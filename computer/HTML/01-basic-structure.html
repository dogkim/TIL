# HTML 태그

HTML 문서의 시작과 끝을 의미

# head 태그

문서의 메타데이터(metadata)를 정의 웹 브라우저에 직접 노출되지 않음.

# meta 태그

메타데이터를 정의하는데 사용

<meta charset="UTF-8"> <!---문자열 정의--->
<meta http-equiv="X-UA-Compatiable" content="IE=edge"> <!---렌더링 엔진 지정--->
<meta name="viewport" content="width=device-width, initial-scale=1.0"> <!---화면 너비를 맞추기 위함--->

# title 태그

문서 제목 지정

 <title>My First web page!</title>

모든 문서는 1개의 title 태그를 사용하여 제목을 지정해야함. 제목은 문서마다 중복되지 않도록 주의

# body 태그

# 블록요소와 인라인 요소

블록요소: 웹브라우저의 공간유무와 상관없이 사용할 때마다 줄바꿈이 되는 태그 ex)<hn>, <p>

인라인요소: 공간이 부족할 때만 줄 바꿈되는 태그 ex) <a>, <span>
