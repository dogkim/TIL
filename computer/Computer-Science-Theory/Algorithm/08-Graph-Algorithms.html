DFS(w, time): 를 방문 시작(discover) 시점을 기록하고 time++, 를 in-progress 상태로 표시. 의 이웃을 순회하며 아직 방문 안 한(unvisited) 이웃 에 대해 time = DFS(u, time) 재귀 호출 후 time++. 모든 이웃 탐색이 끝나면 를 done 상태로 옮기고 종료(finish) 시점 기록.

Topological Ordering ​

DAG(Directed Acyclic Graph)에서 DFS를 돌려 종료 시간(finish time)의 내림차순으로 정점을 나열하면 위상 정렬이 됨.

  • 간선 가 있으면 항상 의 finish time이 보다 커야 함
    • 가 먼저 발견되어 가 의 DFS 트리 자손이 되는 경우: 가 보다 나중에 끝남 ( finish finish)
    • 가 먼저 발견되는 경우: 와 연결된 요소를 모두 탐색한 뒤 로 이동하므로 가 먼저 끝남. 만약 가 의 자손이라면 의 사이클이 생기므로 DAG 가정에 모순 — 즉 이 경우는 애초에 발생할 수 없음
