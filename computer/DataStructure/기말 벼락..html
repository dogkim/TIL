# Levelorder

void level_order(NODE* h){
	NODE* queue[100] = { 0 } ;
	int front = 0, rear = 0;
	NODE* p = NULL;
	
	if(h == NULL){
		return;
	}
	
	queue[rear++] = h;
	while(front < rear){
		p = queue[front++];
		printf("%d ", p->data);
		
		if(p->left){ queue[rear++] = p-> left; }
		if(p->right){ queue[rear++] = p-> right; }
	}
	
	return;
}

# 07 sort

# 1. Iterative sort

시간 복잡도: O(n) 평균적으로 (n+1) / 2

# 2. Binary sort

시간 복잡도: O(log n)

# 3. Insertion sort

앞에서부터 정렬

시간 복잡도 worst case: O(n^2) (내림차순) best case: O(n) (오름차순) 작은 사이즈에 유리

# 4. Quick sort

pivot써서 재귀치는거

시간 복잡도 worst case: sublist두개의 길이가 많이 차이나는 경우 (오름차순, 내림차순) optimal case: O(n log n)

# 5. Merge sort

정렬된 배열 두개를 새 배열에 넣는거 (재귀, 스택)

시간 복잡도 O(n log n) n <= 15 면 그냥 insertion이 더 빠름 공간 복잡도 O(n)

시간 복잡도 O(n log n)
