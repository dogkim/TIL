기술적 관점에서 "왜 연산 장치(CPU/GPU) 연구는 한계에 부딪혔고, 왜 메모리가 이 한계를 깨는 유일한 열쇠가 되었는가"를 설명하는 3단계 기술 발표 개요를 제안합니다. 이 흐름을 따라가면 비전공자도 컴퓨터의 물리적 한계를 명확히 이해할 수 있습니다.

컴퓨터 아키텍처의 물리적 한계와 메모리의 진화 ​

Ⅰ. 도입: 왜 연산 장치(CPU/GPU)의 성장은 멈췄는가? ​

발표의 시작은 연산 장치가 직면한 두 가지 물리적 장벽을 설명하는 것입니다.

① 무어의 법칙(Moore's Law)의 종말 ​

  • 과거에는 반도체 회로 선폭을 좁혀 트랜지스터를 더 많이 집적하기만 하면 성능이 2배씩 늘어났습니다.

  • 하지만 현재 2나노, 3나노 수준까지 도달하면서 원자의 크기 한계 및 양자 역학적 문제(누설 전류)로 인해 미세화 공정을 통한 성능 향상이 물리적 한계에 부딪혔습니다.

② 클럭 속도(Clock Speed)와 파워 월(Power Wall) ​

  • CPU의 속도를 나타내는 클럭을 높이면 트랜지스터가 더 빨리 스위칭하지만, 이 과정에서 열이 기하급수적으로 발생합니다.

  • 칩이 녹아내리는 것을 막기 위해 약 4~5GHz 선에서 클럭 속도의 상승이 강제로 멈추게 되었고, 이를 파워 월(Power Wall)이라 부릅니다.

Ⅱ. 본론 1: 연산 장치의 한계가 만들어낸 '진짜 문제' ​

CPU와 GPU가 성능을 올리기 위해 택한 우회로가 오히려 메모리 병목현상을 극대화했습니다.

① 싱글 코어에서 멀티 코어(GPU)로의 전환 ​

  • 클럭 속도를 못 올리니, 코어(연산 일꾼)의 개수를 수천 개로 늘려 병렬 연산을 하는 GPU 구조가 대세가 되었습니다.

② 폰 노이만 병목현상 (The Memory Wall) ​

  • 연산 일꾼은 수천 명으로 늘어났는데, 데이터를 가져오는 메모리 버스(통로)는 여전히 직렬 구조에 머물러 있었습니다.

  • 이로 인해 연산 장치가 데이터를 기다리며 노는 '메모리 벽(Memory Wall)' 현상이 발생합니다.

③ 데이터 이동의 에너지 비용 (Energy Cost of Data Movement) ​

  • 공학적으로 계산을 수행하는 데 드는 에너지보다, 데이터를 D램에서 CPU/GPU 내부 레지스터까지 이동시키는 데 드는 에너지가 수십에서 수백 배 더 큽니다.

  • 즉, 연산 장치 자체를 아무리 저전력으로 만들어도 데이터를 주고받는 과정에서 발생하는 발열과 전력 소모 때문에 전체 시스템의 전력 장벽(Power Wall)을 깰 수 없게 되었습니다.

Ⅲ. 본론 2: 메모리가 이 한계를 극복하는 3가지 기술적 방식 ​

결국 컴퓨터의 성능과 전력 문제를 해결할 유일한 방법은 메모리의 물리적 구조를 바꾸는 것이었습니다.

1. HBM (High Bandwidth Memory): "도로의 물리적 확장" ​

  • 기술적 원리: 기존 PCB 기판에 올리던 D램을 TSV(실리콘 관통 전극) 기술을 통해 수직으로 쌓고, 실리콘 인터포저라는 미세 기판 위에서 GPU와 바로 옆에 밀착시킵니다.

  • 해결하는 문제: 통로(버스 폭)를 1,024비트 이상으로 늘려 데이터 이동 속도(대역폭)를 획기적으로 늘리고, 물리적 거리를 좁혀 이동 전력을 감소시킵니다.

2. CXL (Compute Express Link): "메모리 자원의 유연화" ​

  • 기술적 원리: 기존의 CPU 독립적인 메모리 규격을 탈피하여, PCIe 인터페이스를 기반으로 CPU, GPU, 가속기가 메모리 자원을 직접 공유할 수 있게 하는 프로토콜입니다.

  • 해결하는 문제: 메모리 용량 확장의 물리적 한계를 깨고, 중복 데이터 이동을 줄여 시스템 전체의 데이터 전송 효율을 극대화합니다.

3. PIM (Processing-In-Memory): "데이터 이동의 완전한 제거" ​

  • 기술적 원리: 메모리 칩 내부에 작은 연산기(ALU)를 탑재하여, 데이터가 CPU/GPU로 이동하지 않고 메모리 안에서 직접 계산을 끝내는 기술입니다.

  • 해결하는 문제: 데이터 이동 자체를 없애기 때문에, 폰 노이만 병목과 전력 소모(Power Wall)를 동시에 해결하는 궁극의 아키텍처로 연구되고 있습니다.

Ⅳ. 결론: 컴퓨터 구조의 패러다임 변화 ​

발표를 요약하며 기술적 의미를 명확히 짚어줍니다.

"지난 70년간 컴퓨터 발전의 역사에서 메모리는 CPU가 시키는 대로 데이터를 저장하고 읽어오는 '수동적인 조연'이었습니다.

하지만 CPU/GPU가 물리적 미세화와 전력 장벽에 가로막힌 지금, 메모리의 혁신(HBM, CXL, PIM) 없이는 단 1%의 성능 향상도 이룰 수 없는 시대가 되었습니다. 이제 메모리는 단순한 저장 장치가 아니라, **연산 장치의 물리적 한계를 깨는 능동적인 '컴퓨팅 파트너'**로 진화하고 있습니다."
