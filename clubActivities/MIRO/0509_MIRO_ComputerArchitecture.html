1. 컴퓨터의 기본 구조 ​

![[Pasted image 20260505171720.png]]

“계산하는 곳(연산 장치)과 기억하는 곳(메모리 장치)이 물리적으로 떨어져 있다”

  • CPU/GPU (일꾼): 문제를 풀고 계산을 담당하는 아주 똑똑한 수학자입니다.
  • 메모리 (책상과 책꽂이): 문제지와 참고서가 놓여 있는 작업 공간입니다.
  • 버스 (통로): 책상에서 일꾼에게 문제지를 나르는 ‘복도’입니다.

컴퓨터가 어떤 작업을 하려면
메모리에서 데이터를 꺼내 → 버스를 지나 → CPU에서 계산
과정을 1초에도 수십억 번씩 반복해야 합니다.

2. 메모리 계층 구조 ​

1. 레지스터 (Register) ​

  • 물리적 위치: CPU 내부 (ALU 인접)
  • 작동 속도: CPU 클럭 사이클과 동기화 (레이턴시 1사이클 미만)
  • 기능: 술·논리 연산의 피연산자 및 결과물, 다음 실행 명령어 주소(PC), 상태 정보(Status)의 실시간 저장

2. 캐시 메모리 (Cache / SRAM) ​

  • 물리적 위치: CPU 칩 내부 (L1, L2, L3 계층 구조)
  • 기능: 참조 국부성에 기반하여 DRAM의 데이터를 복사본으로 보유, CPU와 메모리 간의 속도 차이(Memory Wall) 완화
  • 관계: 모든 SRAM이 캐시는 아니지만(예: 특수 목적의 임시 저장소), 대부분의 CPU 캐시는 SRAM으로 제작됨.

3. 주기억장치 (Main Memory / DRAM) ​

  • 물리적 위치: CPU 외부 메인보드 슬롯 (메모리 버스 연결)
  • 데이터 성격: 휘발성(Volatile), 전원 차단 시 전하 방전으로 데이터 소실
  • 기능: 실행 중인 프로세스의 코드 영역, 데이터 영역, 힙(Heap), 스택(Stack) 상주 공간

4. 보조기억장치 (Secondary Storage / SSD·HDD) ​

  • 물리적 위치: 인터페이스(NVMe, SATA)를 통한 외부 연결
  • 소자 특성: NAND Flash (SSD) / 자기 디스크 (HDD)
  • 데이터 성격: 비휘발성(Non-volatile), 플로팅 게이트나 자성체를 이용한 데이터 영구 보존
  • 기능: 파일 시스템 기반의 데이터 저장, 운영체제(OS) 커널 이미지 및 응용 프로그램 설치 파일 보관

3. 메모리에 주목하는 이유 ​

1. 폰 노이만 병목현상 (Von Neumann Bottleneck) ​

  • 구조적 원인: CPU(연산장치)와 메모리(저장장치)가 분리되어 있으며, 단일 버스(System Bus)를 통해 데이터와 명령어를 전달하는 구조적 한계.

  • 현상: 연산 속도가 아무리 빨라도 데이터를 공급하는 버스의 대역폭(Bandwidth)이 이를 뒷받침하지 못해 시스템 전체 성능이 하향 평준화됨.

2. 메모리 벽 (Memory Wall) ​

  • 성능 격차: 지난 수십 년간 CPU 성능(연산 속도)은 매년 약 60%씩 향상된 반면, DRAM의 접근 속도(Latency) 개선은 매년 약 7% 수준에 머무름.

  • 결과: CPU가 연산을 수행하는 시간보다 메모리로부터 데이터를 기다리는 시간(Memory Stall Cycles)이 더 길어지는 현상 발생.

3. AI 및 LLM 환경에서의 치명성 ​

  • 데이터 규모: 대규모 언어 모델(LLM)은 수천억 개의 파라미터(Weight)를 실시간으로 참조해야 함.

  • 가동률 저하: GPU(NVIDIA H100 등)의 연산 능력(TFLOPS)은 비약적으로 높으나, 해당 연산을 처리하기 위해 필요한 데이터를 메모리(VRAM)에서 읽어오는 속도가 병목이 됨.

  • 효율성: GPU의 연산 유닛이 데이터 입력을 기다리며 유휴 상태(Idle)에 머무는 시간이 증가하여, 고가 하드웨어의 자원 낭비 초래.

2. 두 번째 장벽: 파워 월 (전력과 발열의 문제) ​

![[Pasted image 20260505173135.png|485]]

병목현상이 생기자, 반도체 설계자들은 CPU의 속도(클럭 속도)를 더 높여서 억지로 문제를 해결하려 했습니다. 하지만 여기서 두 번째 장벽인 ‘파워 월(Power Wall)’을 만납니다.

반도체 칩은 전기를 더 많이 주면 빨라지지만, 그만큼 열이 기하급수적으로 발생합니다. 일정 수준을 넘어가면 칩이 녹아내리기 때문에, CPU의 클럭 속도를 높이는 방식은 약 15~20년 전부터 물리적 한계에 부딪혔습니다.

그런데 여기서 아주 놀라운 반도체의 비밀이 있습니다. AI 반도체가 소모하는 전체 전력 중 계산(연산)을 하는 데 쓰이는 전력은 얼마 되지 않습니다. 전체 전력의 약 60% 이상이 바로 ‘데이터를 메모리에서 꺼내 CPU로 옮기는 과정’에서 낭비됩니다.

즉, 데이터를 책상(DRAM)에서 일꾼(CPU)에게 가져오는 거리가 너무 멀고, 데이터를 주고받는 횟수가 너무 많아서 전기가 새고 열이 발생하는 것입니다. 결국 이 전력 장벽(파워 월)을 깨기 위해서라도 데이터의 이동을 혁신하는 메모리 연구가 필수적이게 되었습니다.

Ⅳ. 해법 ​

이제 왜 연산 장치가 아니라 메모리를 뜯어고쳐야 하는지 이해가 되셨을 겁니다. 그렇다면 지금 전 세계 반도체 기업들은 이 문제를 어떻게 해결하고 있을까요? 바로 시장에서 가장 핫한 세 가지 기술입니다.

1. HBM (고대역폭 메모리): "통로의 물리적 확장" ​

가장 먼저 시장을 뒤흔들고 있는 HBM입니다.

기존 D램은 메인보드에 바둑판처럼 평면으로 깔려 있었습니다. HBM은 이 고정관념을 깨고, D램을 아파트처럼 수직으로 8층, 12층씩 높게 쌓아 올렸습니다. 그리고 칩에 미세한 구멍을 뚫어 전극으로 연결하는 TSV(실리콘 관통 전극) 기술을 사용했습니다.

이것이 왜 대단할까요?

  • 일반 D램: 데이터를 주고받는 도로가 64차선에 불과합니다. 대신 스포츠카처럼 엄청나게 빠른 속도로 데이터를 실어 나릅니다.

  • HBM: 도로를 무려 1,024차선, 최신 제품은 2,048차선으로 대폭 늘렸습니다.

비유하자면, 스포츠카 64대가 왕복하던 좁은 도로를 대형 화물트럭 1,024대가 동시에 출발하는 초광대역 고속도로로 만든 것입니다. 속도를 억지로 올리지 않아도 한 번에 엄청난 데이터를 쏟아부어 주기 때문에 폰 노이만 병목을 해결하고, 물리적 거리를 좁혀 전력 소모(파워 월)까지 낮췄습니다.

2. CXL (Compute Express Link): "책상의 무한 확장" ​

두 번째는 차세대 기술로 꼽히는 CXL입니다.

기존의 컴퓨터 구조에서는 CPU 하나에 꽂을 수 있는 D램의 개수가 엄격하게 제한되어 있었습니다. 책상이 좁아서 올려둘 수 있는 책의 양이 한정적이었던 것이죠.

CXL은 이 책상의 한계를 깨기 위해 만들어진 새로운 연결 규격입니다. 마치 컴퓨터에 SSD를 여러 개 꽂아 용량을 늘리듯, D램을 무한정 연결해 서버의 메모리 용량을 획기적으로 늘려줍니다. 빅테크 기업들 입장에서는 비싼 서버를 통째로 바꾸지 않고도 메모리를 확장할 수 있는 최고의 가성비 솔루션입니다.

3. PIM (Processing-In-Memory): "데이터 이동의 완전한 제거" ​

마지막은 미래 기술인 PIM입니다.

앞서 데이터 이동 과정에서 전력의 60%가 낭비된다고 말씀드렸습니다. 그렇다면 아예 데이터를 이동시키지 않으면 어떨까? 라는 생각에서 출발한 기술입니다.

PIM은 메모리 칩 내부에 아주 작은 계산기(ALU)를 직접 탑재하는 기술입니다. 데이터를 CPU로 가져오지 않고 책상(메모리) 위에서 직접 계산을 끝내버린 뒤 결과만 CPU에 전달합니다. 데이터를 주고받을 필요가 없으니 전력 소모를 최대 10배 이상 줄일 수 있어 파워 월을 깨는 궁극의 아키텍처로 주목받고 있습니다.

Ⅴ. 결론 (27 ~ 30분): 조연에서 지배자로, 메모리가 판을 바꾼다 ​

1. 두 공룡의 HBM 경쟁 구도 ​

그렇다면 이 뜨거운 메모리 시장에서 우리 한국의 두 공룡, SK하이닉스와 삼성전자는 어떤 전략을 취하고 있을까요? 두 기업의 차별화된 무기를 비교해 보면 매우 흥미롭습니다.

  • SK하이닉스 (동맹군 전략): 엔비디아, 그리고 세계 1위 파운드리 기업인 TSMC와 강력한 삼각 동맹을 맺었습니다. 열 방출이 뛰어난 검증된 패키징 기술(MR-MUF)을 앞세워 시장의 신뢰를 얻었고, 현재 AI 메모리 시장의 주도권을 꽉 쥐고 있습니다.

  • 삼성전자 (원스톱 솔루션 전략): 전 세계에서 유일하게 메모리 생산, 파운드리(칩 위탁생산), 그리고 패키징까지 혼자서 다 할 수 있는 종합 반도체 기업(IDM)입니다. 최근 차세대 HBM4(6세대)의 세계 최초 양산 및 공급 물량 완판을 기록하며 거세게 반격을 시작했습니다.
