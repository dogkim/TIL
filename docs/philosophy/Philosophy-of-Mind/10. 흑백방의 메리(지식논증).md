## 지식논증

**프랭크 잭슨(Frank Jackson)**은 물리주의(모든 사실은 물리적 사실에 다름 아니라는 입장)를 겨냥한 **지식논증(knowledge argument)**을 제시한다. 워밍업 격인 **프레드 사유실험**부터 보자.

> 프레드는 일반 사람에게는 똑같이 보이는 빨강의 두 색조를 구분할 수 있고, 각각을 "빨강1", "빨강2"라 부른다. 우리가 프레드의 두뇌·신경체계에 대해 모든 것을 알고 있다 해도, 우리는 여전히 프레드에게 빨강1과 빨강2가 어떻게 보이는지 알지 못한다.

| | |
|---|---|
| P1 | 우리는 프레드의 경험에 대한 모든 물리적 사실을 안다 |
| P2 | 우리는 여전히 프레드의 경험에 대해 모르는 것이 있다 |
| C | 따라서 물리적 사실과는 구별되는 사실이 존재한다 |

이를 정교하게 발전시킨 것이 **흑백 방의 메리(Mary the color scientist)** 사유실험이다.

> 메리는 태어날 때부터 흑백 방에 갇혀 흑백 책과 흑백 텔레비전으로만 교육받으며 자란다. 이런 방식으로 메리는 세계의 물리적 본성에 관해 모든 것 — 우리 자신과 환경에 대한 모든 물리적 사실 — 을 알게 된다. 그러나 메리가 정말로 모든 것을 아는 것 같지는 않다. 왜냐하면 그가 흑백 방에서 풀려났을 때, 이를테면 빨간색을 본다는 것이 어떠한 것인지를 비로소 배우게 되기 때문이다.

| | |
|---|---|
| P1 | 메리는 흑백 방에서 나오기 전에 모든 물리적 사실을 알고 있었다 |
| P2 | 메리는 방에서 나온 후 새로운 사실(빨간색이 그렇게 보인다는 사실)을 알게 된다 |
| C | 따라서 물리적 사실과는 구별되는 사실이 존재한다 |

물리주의를 "모든 사실은 물리적 사실이다"라는 주장으로 이해한다면, 이 논증은 물리주의를 반박하는 셈이 된다. 잭슨은 메리가 새로 배우는 그 사실을 경험의 **감각질(qualia)**에 관한 사실로 본다. 조금 더 정교하게 재구성하면:

| | |
|---|---|
| P1 | 메리는 방에서 나가기 전에 모든 (관련된) 물리적 사실을 알고 있었다 |
| P2 | 따라서 물리주의가 참이라면, 메리는 방에서 나오기 전에 이미 모든 사실을 알고 있었다 |
| P3 | 메리는 방에서 나온 후 새로운 것을 배운다 |
| P4 | 메리가 새로운 것을 배운다면, 그는 새로운 사실을 알게 되는 것이다 |
| P5 | (P3, P4로부터) 방에서 나온 후 메리는 새로운 사실을 알게 된다 |
| C | (P2, P5로부터) 따라서 물리주의는 거짓이다 |

**전제 검토**

- **P1**: 메리가 모든 물리적 지식을 가져야 한다고 가정할 필요는 없다 — 색깔 경험에 관련된 물리적 지식만 완전하다고 가정해도 충분하다. 그렇다면 단지 색을 경험한 적이 없다는 이유만으로 어떤 물리적 사실을 몰랐다고 보기는 어렵다.
- **P2**: 물리주의의 정의와 P1으로부터 명백히 따라 나온다.
- **P3**: 일부 철학자는 우리가 지금 아는 물리적 지식이 너무 미약해서, 메리만큼 방대한 물리적 지식을 가진 사람이 실제로 어떤 상황에 있게 될지 우리가 상상조차 할 수 없다고 반론한다.
- **P4**: 많은 철학자들이 지식논증의 **가장 약한 고리**로 지목하는 전제다 — 이하의 반론들은 대개 이 P4를 공략한다.

## 메리가 얻은 것은 어떤 종류의 지식인가

지식은 흔히 세 종류로 구분된다.

| 종류 | 예시 |
|---|---|
| **명제적 지식(knowing that)** — "사실적 지식" | "S는 p라는 것을 안다" |
| **능력으로서의 지식(knowing how)** | "나는 자전거를 탈 줄 안다" |
| **면식(대면)에 의한 지식(knowing what / knowledge by acquaintance)** | "나는 동팔이는 알지만 그의 부모님은 모른다" |

많은 물리주의자들은 P4를 부정하면서, 메리가 획득한 것은 (i) **명제적** 지식이 아니라 (ii) 또는 (iii)의 지식이라고 봄으로써 지식논증에 대응하려 한다. (참고: 어떤 철학자들은 애초에 (ii), (iii)이 진짜 "지식"이 아니거나 결국 명제적 지식으로 환원된다고 보는데, 이 견해가 옳다면 아래의 물리주의자 전략은 실패로 돌아간다 — 이는 여전히 뜨거운 논쟁거리다.)

## 능력 가설 (the Ability Hypothesis)

**능력 가설**에 따르면, 메리가 방에서 나와 얻은 것은 (ii) 능력으로서의 지식이다. 이 입장의 선구자 **네미로우(Lawrence Nemirow)**는 네이글의 박쥐 논증에 대한 응답으로 이렇게 주장한다.

> "이해의 어떤 방식은 사실을 파악하는 데 있는 것이 아니라, **능력을 획득**하는 데 있다. … 만일 내가 의지대로 빨강을 시각화할 수 있다면, 이것이 곧 빨강을 보는 경험을 이해하는 것이다. … 우리는 이해의 대상으로 주관적 사실 같은 것을 가정하지 않고도 경험에 대한 이해의 주관성을 설명할 수 있다. 또한 이 견해는 경험에 대한 우리의 주관적 이해가 왜 언어적으로 소통 불가능한지도 설명한다."

**데이빗 루이스(David Lewis)**는 정확히 어떤 능력인지를 구체화한다 — "능력 가설에 따르면, 어떤 경험을 갖는 것이 어떠한 것인지를 아는 것은 그 경험을 **기억(remember)**하고, **상상(imagine)**하고, **인지(recognize)**할 수 있는 능력을 소유하는 것에 다름 아니다." 즉 메리는 방에서 나와 빨강을 처음 본 이후에야, 그 경험을 기억할 수 있고, 자신의 의지대로 그것을 상상(시각화)할 수 있으며, 다시 빨강을 보았을 때 그것이 같은 색이라고 알아챌 수 있게 된다는 것. 루이스는 이런 능력이 know-how이기 때문에 명제적 지식으로 환원될 수 없다고 본다.

대부분의 철학자들은 메리가 이런 종류의 능력을 얻었다는 것 자체는 인정한다. 문제는 **그것이 전부냐**는 것이다.

## 마리안나 사례 — 능력 가설에 대한 반박 시도

능력 가설을 반박하기 위해 다음과 같은 변형 사례가 제시된다.

1. **단계 1**: 마리안나는 메리와 같이 흑백 방에서 모든 물리적 지식을 획득한다.
2. **단계 2**: 방에서 완전히 풀려나기 전, 마리안나는 빨강과 초록에 대한 경험을 하게 되는데, 그것이 정확히 어떤 색인지는 전혀 모르는 방식으로 경험한다.
3. **단계 3**: 방에서 풀려난 마리안나는 토마토를 보고, 단계 2에서 경험했던 색이 바로 "빨강"이었음을 깨닫는다.

문제는, 마리안나는 이미 단계 2에서 능력 가설이 말하는 "능력"(기억·상상·인지)을 획득했음에도, 단계 3에서 또 다른 무언가를 새로 알게 되는 것 같다는 점이다 — 그렇다면 능력만으로는 메리/마리안나가 얻는 것을 다 설명하지 못하는 것 아닌가?

다만 이 강의는 마리안나가 단계 3에서 얻는 지식이 정말로 물리주의에 위협이 될 만한 종류의 지식인지 의심스럽다고 지적한다 — 이는 그저 옆 사람이 "그건 빨강에 대한 경험이었어"라고 일러주기만 해도 얻어질 수 있는 종류의(명제적) 지식이 아닌가 하는 것.

## "옛 사실, 새로운 방식" 반론

또 다른 부류의 반론 역시 P4를 겨냥하는데, 이번엔 **개념**에 호소한다.

> "일인칭 관점에서 우리가 배우는 사실은 [사실은] 물리적 사실이다. 그래도 우리는 과학이 제공하는 제삼자 관점과는 매우 상이한 방식으로 이 사실에 접근한다. … 흑백 방에서 나온 뒤 메리는 낡고 똑같은 사실을 **새로운 방식**으로 익히게 된다. 그리고 마침내, 경험 자체를 가져야만 파악될 수 있는 일정한 개념 — **현상적 개념(phenomenal concept)** — 이 존재한다는 것이 드러났다."

즉 메리는 새로운 **사실**을 알게 된 것이 아니라, 이미 알고 있던 (물리적) 사실에 대해 새로운 **개념**을 통해 알게 되었을 뿐이라는 주장이다. 일견 그럴듯하지만, 이는 하나의 수수께끼("새로운 사실이란 무엇인가")를 다른 수수께끼("현상적 개념이란 정확히 무엇인가")로 바꿔치기한 것에 불과할 수도 있다는 문제가 남는다.
