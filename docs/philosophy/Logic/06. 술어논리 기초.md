## 명제논리의 한계

"모든 한국 사람은 성질이 급하다. 철수는 한국 사람이다. 따라서 철수는 성질이 급하다"는 명백히 타당한 논증이지만, 명제논리로 번역하면 $A, B \therefore C$ 처럼 서로 무관한 문장기호가 되어버려 타당성이 왜 성립하는지 전혀 드러나지 않는다. 명제논리는 **단순문장을 통째로 하나의 단위로 취급**하기 때문에 문장 **내부의 구조**를 다루지 못한다. 이를 해결하려는 언어가 **술어논리(predicate logic)**다.

## 술어논리의 기본 구성요소

가장 단순한 문장은 **이름 + 술어**로 이루어진다: "철수는 한국인이다" → 철수(이름) + 한국인이다(술어).

| 요소 | 기호 | 역할 |
|---|---|---|
| **술어기호** | 대문자 $A, B, C, \dots$ | 속성을 지시 |
| **개체상항(individual constant)** | 소문자 $a, b, c, \dots, w$ | 특정 대상(이름)을 지시 |
| **개체변항(individual variable)** | $x, y, z$ | 임의의(불특정) 대상을 지칭 |

예: "철수는 한국인이다" → $Kc$. 여기에 명제논리와 같은 연결사($\sim, \wedge, \vee, \to, \leftrightarrow$)를 그대로 적용해 복합문장을 만들 수 있다.

## 양화사

"모든 것은 소멸한다" / "어떤 것은 소멸한다" 같은 문장은 "철수"처럼 특정 대상을 가리키는 이름이 없다. 이를 다루기 위해 **문장함수(sentential function)**와 **양화사(quantifier)** 개념을 도입한다.

- $Px$ ("$x$는 소멸한다") 는 그 자체로 진리치가 없는 **문장함수**다 — $x$가 특정 대상으로 채워지지 않았기 때문
- **보편양화사** $(x)$: "모든 것에 대해" → $(x)Px$ = "모든 것이 소멸한다"
- **존재양화사** $(\exists x)$: "어떤 것이 존재해서" → $(\exists x)Px$ = "어떤 것이 소멸한다"

문장함수에 양화사를 붙이면 비로소 진리치를 갖는 **문장**이 된다.

### 자주 쓰이는 동치 관계

| 원문 | 기호화 |
|---|---|
| 모든 것이 아름다운 것은 아니다 | $\sim(x)Bx$ |
| 어떤 것은 아름답지 않다 | $(\exists x)\sim Bx$ |
| 아름다운 것은 존재하지 않는다 | $\sim(\exists x)Bx$ |
| 모든 것이 아름답지 않다 | $(x)\sim Bx$ |

일반적으로: $\sim(x)Fx :: (\exists x)\sim Fx$, $\;\sim(\exists x)Fx :: (x)\sim Fx$, $\;(\exists x)Fx :: \sim(x)\sim Fx$, $\;(x)Fx :: \sim(\exists x)\sim Fx$.

### 보편 명제는 →, 존재 명제는 ∧ — 가장 흔한 실수 포인트

- "모든 경북대생은 똑똑하다" → $(x)(Kx \to Sx)$ ("경북대생이면 똑똑하다")
- "어떤 경북대생은 똑똑하다" → $(\exists x)(Kx \wedge Sx)$ ("경북대생이면서 똑똑한 것이 존재")

여기서 $\to$와 $\wedge$를 바꿔 쓰면 의미가 완전히 달라진다: $(x)(Kx \wedge Sx)$는 "모든 것이 경북대생이면서 똑똑하다"는 훨씬 강한(대개 거짓인) 주장이 되어버린다.

- "오직 경북대생만이 똑똑하다" → 똑똑한 모든 사람은 경북대생 → $(x)(Sx \to Kx)$ ("only" 표현은 방향이 반대로 뒤집힘에 주의)

### 논의영역 제한

일상언어의 "모든"은 보통 세계의 모든 것이 아니라 적절한 **논의영역(domain of discourse)**으로 제한된다 (예: "모든 사람이 시험을 잘 봤다" = 이 수업을 듣는 사람들 한정). 논의영역을 좁게 잡을수록 번역이 단순해진다 — 예를 들어 논의영역을 "논리학을 수강하는 경북대생의 집합"으로 제한하면 "모든 논리학 수강 경북대생은 똑똑하다"는 그냥 $(x)Sx$가 된다.

## 보편명제·존재명제와 사례

| 명제 형태 | 이름 |
|---|---|
| $(x)Fx$ | 보편명제(전칭명제) |
| $(\exists x)Fx$ | 존재명제(특칭명제) |

$Fa$는 그 **사례(instance)**, $\sim Fa$는 **부정적 사례**라 부른다. 보편명제를 부정하면 존재명제와 동치가 되고, 존재명제를 부정하면 보편명제와 동치가 된다.

### 사례를 통한 논증의 타당성/부당성

| | 보편명제 → 사례 | 사례 → 보편명제 | 존재명제 → 사례 | 사례 → 존재명제 |
|---|---|---|---|---|
| 이름 | 보편예화(UI) | 보편일반화 | 존재예화 | 존재일반화(EG) |
| 타당성 | **타당** | 부당 | 부당 | **타당** |

정리하면: **보편명제는 그 긍정적 사례로 증명될 수 없지만, 부정적 사례로 반박될 수 있다.** **존재명제는 그 긍정적 사례로 증명될 수 있지만, 부정적 사례로 반박될 수 없다.**

## 술어논리 언어의 통사론 (엄밀한 정의)

### 기본 어휘

술어기호($A, B, \dots$), 개체상항($a, b, \dots$), 개체변항($x, y, z$), 양화사($\exists$; 보편양화사는 별도 기호 없이 $(x)$로 표기), 논리연결사, 괄호.

### 적형식 규칙

1. 술어기호 + 개체상항/변항 (예: $Ab$, $Bx$)은 적형식이다.
2. $p$가 적형식이면 $\sim p$도 적형식이다.
3. $p, q$가 적형식이면 $(p \wedge q), (p \vee q), (p \to q), (p \leftrightarrow q)$도 적형식이다.
4. $p$가 적형식이면 $(x)p$, $(\exists x)p$도 적형식이다.

### 영역(scope), 구속변항과 자유변항

$(x)p$에서 $p$에 해당하는 부분을 양화사 $(x)$의 **영역(scope)**이라 부른다. $(x)(Fx \to Gx)$에서 영역은 $(Fx \to Gx)$ 전체이지만, $(x)Fx \to Gx$에서 영역은 $Fx$뿐이다.

- 양화사의 영역 **안에** 있는 변항 = **구속변항(bound variable)**
- 그렇지 않은 변항 = **자유변항(free variable)**

**문장(sentence)의 정의**: 술어논리 언어의 문장은 **자유변항이 나타나지 않는 적형식**이다. (자유변항이 남아있는 적형식 = 문장함수, 아직 진리치가 없음.)

## 술어논리 언어의 의미론: 해석(interpretation)

술어논리 기본 요소에 의미(외연)를 할당하는 것을 **해석(interpretation)**이라 부른다. 해석은 세 요소로 구성된다.

| 요소 | 할당 대상 |
|---|---|
| **논의영역(domain)** | 관심 대상들의 (공집합이 아닌) 집합 |
| **개체상항** | 논의영역에 속하는 특정 개체 |
| **술어기호** | 어떤 속성, 즉 대상들의 집합(논의영역의 부분집합) |

의미론적 규칙: $Fa$는 $a$에 할당된 대상이 $F$에 할당된 집합에 속할 때 참; $(x)Fx$는 논의영역의 모든 대상이 $Fx$를 만족할 때 참; $(\exists x)Fx$는 그런 대상이 하나라도 있을 때 참. 연결사는 명제논리와 동일한 방식으로 처리.

**예시 해석**: 논의영역 = 강의실 사람들, $A$=성인, $M$=남자, $W$=여자, $k$=권홍우. 이 해석 하에서 $Mk$는 참, $Wk$는 거짓, $(x)Ax$는 참(모두 성인) 등을 판정할 수 있다. **대부분의 문장은 해석에 따라 참/거짓이 달라진다.**

### 해석을 이용한 논리적 성질/관계의 정의

| 개념 | 정의 |
|---|---|
| **논리적 참(필연적 참)** | 모든 해석에서 참 |
| **자기모순** | 모든 해석에서 거짓 |
| **우연적 문장** | 어떤 해석에서는 참, 어떤 해석에서는 거짓 |
| **논리적 동치** | 모든 해석에서 같은 진리치 |
| **논리적 모순** | 모든 해석에서 다른 진리치 |
| **일관적** | 둘 다 참인 해석이 존재 |
| **타당성 (논증)** | 전제가 참이면서 결론이 거짓인 해석이 존재하지 않음 |

**주의 — 술어논리의 "동어반복" 개념은 명제논리보다 좁다**: 술어논리에서도 논리적 참은 있지만, "동어반복"이라는 말은 **진리함수적 연결사의 의미만으로** 필연적 참이 되는 경우로 한정한다. 예를 들어 $(x)(Mx \vee \sim Mx)$는 논리적 참(필연적 참)이지만, 명제논리 형태로 봤을 때 $Mx \vee \sim Mx$가 동어반복이 아니므로(변항이 있어 명제논리로 직접 번역 불가) **엄밀히는 동어반복이 아니다**. 반면 $(\exists x)Fx \vee \sim(\exists x)Fx$는 전체를 $p \vee \sim p$ 형태로 볼 수 있으므로 동어반복이다.

해석의 **사례**를 통해 논증이 **타당하지 않음**을 보이는 것은 (명제논리의 반례법을 술어논리로 확장한 것으로) 가능하지만, 논리적 참·동치·타당성처럼 "모든 해석에서" 성립함을 보이려면 사례 하나로는 부족하고 다른 방법(뒤에 나올 밴다이어그램, 자연연역)이 필요하다.
