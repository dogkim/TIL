## 자연연역이란

진리표 방법은 **효과적**이지만 **효율적이지 않다** ([[04. 명제논리 구문론과 진리표|04]]). 예를 들어 4개의 전제로 이루어진 간단한 논증도 8줄짜리 진리표가 필요할 수 있다. 반면 우리는 직관적으로 다음처럼 추론한다.

1. NC나 삼성 중 적어도 한 팀이 한국시리즈에 나온다. (전제)
2. NC는 나오지 못한다. (전제)
3. 기아가 나오면 삼성은 못 나온다. (전제)
4. 삼성은 나온다. (1, 2, 선언적 삼단논법)
5. 기아는 나오지 못한다. (3, 4, 후건부정법)

**자연연역(natural deduction)**은 이런 방식의 증명을 체계화한 것 — 인간이 사고하는 "자연스러운" 방식을 닮았다고 하여 붙은 이름. 증명의 각 줄은 전제이거나, 이전 줄들로부터 **추론 규칙**에 의해 자명하게 따라 나오는 것이다. 추론 규칙에는 **함축 규칙**과 **대치 규칙**, 두 종류가 있다.

### 증명의 형식

증명은 3열: (1) 행 번호, (2) 문장, (3) 그 문장이 어떤 행·규칙에서 나왔는지. 각 단계가 규칙에 의해 타당성이 보장되므로, 이를 이어붙인 전체 증명도 타당성을 보장한다 — **전제로부터 결론까지의 증명이 존재하면 그 논증은 타당**하다고 결론지을 수 있다.

주의할 점: 함축 규칙은 문장의 **일부분**이 아니라 **문장 전체**의 형태에 대해서만 적용해야 한다 (아래 대치 규칙과의 핵심 차이).

## 함축 규칙 (9개)

| 이름 | 형식 |
|---|---|
| 전건긍정법 (MP) | $p \to q,\; p \;\vdash\; q$ |
| 후건부정법 (MT) | $p \to q,\; \sim q \;\vdash\; \sim p$ |
| 가정적 삼단논법 (HS) | $p \to q,\; q \to r \;\vdash\; p \to r$ |
| 선언적 삼단논법 (DS) | $p \vee q,\; \sim p \;\vdash\; q$ |
| 구성적 양도논법 (CD) | $(p \to q) \wedge (r \to s),\; p \vee r \;\vdash\; q \vee s$ |
| 연언지 단순화 (Simp) | $p \wedge q \;\vdash\; p$ |
| 연언 (Conj) | $p,\; q \;\vdash\; p \wedge q$ |
| 선언지 첨가 (Add) | $p \;\vdash\; p \vee q$ |
| 흡수규칙 (Abs) | $p \to q \;\vdash\; p \to (p \wedge q)$ |

각 규칙에서 $p, q, r, s$ 자리에 아무 문장이나 대입해도 타당한 논증이 되며, 이는 진리표로 쉽게 확인 가능하다.

## 대치 규칙 (10개)

함축 규칙과 달리, 대치 규칙은 논리적 동치 관계이므로 **문장의 일부분에도 적용 가능**하다.

| 이름 | 동치 |
|---|---|
| 드모르간 (DM) | $\sim(p \wedge q) :: (\sim p \vee \sim q)$, $\;\sim(p \vee q) :: (\sim p \wedge \sim q)$ |
| 교환법칙 (Com) | $(p \vee q) :: (q \vee p)$, $\;(p \wedge q) :: (q \wedge p)$ |
| 결합법칙 (Assoc) | $p \vee (q \vee r) :: (p \vee q) \vee r$, $\;p \wedge (q \wedge r) :: (p \wedge q) \wedge r$ |
| 배분법칙 (Dist) | $p \wedge (q \vee r) :: (p \wedge q) \vee (p \wedge r)$, $\;p \vee (q \wedge r) :: (p \vee q) \wedge (p \vee r)$ |
| 이중부정 (DN) | $p :: \sim\sim p$ |
| 대우규칙 (Trans) | $p \to q :: \sim q \to \sim p$ |
| 단순함축 (Impl) | $p \to q :: \sim p \vee q$ |
| 단순동치 (Equiv) | $p \leftrightarrow q :: (p \to q) \wedge (q \to p)$, $\;p \leftrightarrow q :: (p \wedge q) \vee (\sim p \wedge \sim q)$ |
| 수출입규칙 (Exp) | $(p \wedge q) \to r :: p \to (q \to r)$ |
| 동어반복 (Taut) | $p :: p \vee p$, $\;p :: p \wedge p$ |

대치 규칙의 배후 원리: 두 문장이 논리적 동치라는 것은 같은 의미를 공유한다는 것이므로, 증명의 어느 부분을 같은 의미의 다른 표현으로 바꿔도 논증의 타당성에는 영향이 없다.

### 증명 예시

$$1.\; F \to G \quad 2.\; F \vee H \quad 3.\; \sim G \quad 4.\; H \to (G \to I) \; / \; F \to I$$
$$5.\; \sim F \;(1,3\;MT) \quad 6.\; H \;(2,5\;DS) \quad 7.\; G \to I \;(4,6\;MP) \quad 8.\; F \to I \;(1,7\;HS)$$

**요령**: 결론의 형태를 보고 거꾸로 어떤 중간 결과가 필요할지 역산하는 전략이 유용하다. 진리표와 달리 자연연역에는 증명을 자동으로 찾아주는 기계적 절차가 없으므로, 시행착오를 통해 증명을 구성해야 한다.

## 조건증명법과 간접증명법

19개의 규칙(함축 9 + 대치 10)만으로 모든 타당한 논증의 증명을 구성할 수 있지만("완전"하지만), 다음 두 방법을 추가하면 훨씬 편리해진다. 원칙적으로 없어도 되는 방법이라는 점에 유의.

### 조건증명법 (Conditional Proof, CP)

조건문 $p \to q$를 증명하는 방법. 아이디어: 전건 $p$를 **임시로 가정**(P for CP)하고, 이 가정과 다른 전제들로부터 후건 $q$를 도출하면, "$p \to q$"라고 결론 내릴 수 있다. 가정에 의존하는 줄들은 들여쓰기로 표시하고, $q$ 도출에 성공하면 가정을 "제거"하면서 $p \to q$를 얻는다(그 근거로 "$m$-$n$, CP"라고 표시).

```
3.  p          P for CP
...
n.  q          ...
n+1. p → q     3-n, CP
```

### 간접증명법 (Indirect Proof, IP)

**귀류법(reductio ad absurdum)**을 체계화한 것. $p$를 증명하려면 그 부정 $\sim p$를 임시로 가정하고, 여기서 모순(어떤 명제와 그 부정을 동시에 도출)이 나오면 $\sim p$라는 가정이 틀렸으므로 $p$라고 결론 내린다.

```
3.  ~p         P for IP
...
n.  q ∧ ~q     ...
n+1. p         3-n, IP
```

두 방법을 중첩해서 함께 쓸 수도 있다 (조건증명 안에 간접증명을 넣는 등).

## 건전성과 완전성 (자연연역 체계에 대해)

**주의**: 여기서 말하는 건전성·완전성은 [[01. 논증과 타당성|01]]에서 다룬 (논증 자체의) 건전성 개념과는 **다른** 개념이다. 여기서는 **자연연역 체계**라는 증명 방법 자체의 속성을 말한다.

타당성은 참·거짓 개념을 포함하는 **의미론적** 개념인 반면, 자연연역에 의한 도출가능성은 의미와 무관한 **구문론적** 개념이다. 둘이 일치한다는 보장이 있는가?

| 개념 | 정의 |
|---|---|
| **건전성(soundness)** | 자연연역으로 도출 가능하면, 그 논증은 반드시 (진리표로도) 타당하다 |
| **완전성(completeness)** | 논증이 타당하면, 전제로부터 결론을 자연연역으로 반드시 도출할 수 있다 |

이 강의에서 배운 자연연역 체계는 건전한 동시에 완전하도록 신중하게 구성된 체계다. 완전성이 성립한다는 것은 강한 실천적 함의를 갖는다: **타당한 논증인데 증명을 구성하지 못했다면, 그것은 여러분의 잘못**(체계의 한계가 아니라 실력 문제)이라는 뜻. 다만 자연연역 자체는 (진리표와 달리) 증명을 항상 자동으로 찾아주는 **효과적** 절차는 아님에 유의.
