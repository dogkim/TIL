## 방법서설

원제: 이성을 잘 인도하고, 학문에 있어 진리를 탐구하기 위한 방법서설.

**학문을 위한 방법 4가지**
1. **명증성**: 명석하고 판명하게 참이라고 인식한 것 외에는 어떤 것도 참으로 받아들이지 않음
2. **분석(분해)**: 검토할 문제를 가능한 한 작은 부분으로 나눔
3. **종합(합성)**: 가장 단순하고 알기 쉬운 것부터 차례로 복잡한 것에 대한 인식으로 올라감
4. **열거**: 하나도 빠뜨리지 않았다고 확신할 수 있을 만큼 완벽하게 열거하고 전체적으로 검토함

## 고대 철학과의 차이점

물음의 초점이 대상이 아닌 **주체**로 향하게 됨. 외부세계나 대상이 아니라, 의심하고 사유하는 '나'의 존재를 철학의 제1원리로 삼음으로써 철학의 중심이 대상에서 주체로 옮겨감.

## 코기토(Cogito) 논증

모든 것을 의심(방법적 회의)해도 '지금 의심하고 있다는 것' 자체는 의심할 수 없음 — "나는 생각한다, 고로 존재한다."

**확실성의 요소**
1. 1인칭 형식
2. 현재형
3. 사유작용/자기의식작용과 떨어져 있는 것에 대해서는 악신(사악한 정령)이 개입할 수 있음

**코기토에 대한 비판**
1. 데카르트는 의식의 흐름을 인지하고 있을 뿐인데, 이를 통해 '사유하는 나'(실체)를 설명함 — 실체란 어떤 속성을 담지하는 궁극적 담지자이며, 속성을 가지되 다른 존재의 속성은 아닌 것. '나'는 사고라는 속성을 가지며 다른 존재의 속성이 아니라고 주장한 것인데, 이 추론이 정당한가?
2. 이러한 추론의 형식 자체가 악신의 가설 문제에 걸리지 않는가? → 데카르트의 답: 이것은 추론이 아니라 **직관**이다 (전제로부터 결론을 이끌어내는 추론 과정이 아니라, 사유하는 동시에 직접적으로 파악되는 것이므로 악신의 개입 여지가 없음)

## 데카르트의 순환논증 (Cartesian Circle)

1. 명석판명한 지각이 확실한 지식이기 위해서는 신이 존재해야 한다.
2. 신이 존재한다는 것은 명석판명하게 지각된다.
3. 따라서 신은 존재한다.
4. 따라서 명석판명한 지각은 확실한 지식이다.

→ 신의 존재를 명석판명한 지각으로 증명하면서, 그 명석판명한 지각의 신뢰성 자체를 신의 존재로 보증하려 하는 순환 구조라는 비판.

## 아르키메데스적 기획

아르키메데스가 "지구를 움직이기 위해 단 하나의 확고부동한 점만" 찾으려 했듯, 데카르트 역시 학문의 확고한 토대를 세우기 위해 **"확실하고 흔들리지 않는 최소한의 것"**을 발견하고자 함. 목적은 하나의 확실한 진리를 발견하고, 그것을 토대로 모든 학문의 체계를 재건축하는 것.

## 표상주의와 이원론

**마음/의식(표상)**과 **외부세계(대상)**를 구분하는 구도 — 표상을 매개로 인식한다는 **표상주의**의 입장. (배와 선원의 비유: 영혼이 없으면 육체의 움직임이 불가능하다는 방식으로 플라톤의 이원론을 재서술)

세상에 존재하는 모든 것은 **형상적 실재성**을 지님.
