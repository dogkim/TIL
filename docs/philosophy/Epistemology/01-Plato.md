## 인간의 목표와 철학의 목적 - 인식론

- 모든 인간의 목표는 인간다운 삶의 성취
- 철학의 목적은 인간이 인간다운 삶을 위해 덕을 갖추도록 인도하는 것

## 덕과 지식

### 덕(arete)
- ~에 대한 탁월함
- 인간의 덕: 인간으로 마땅히 수행해야 하는 기능에 있어서의 탁월함
- 탁월함 = 유익함 = 앎

### 지식(앎)
- **절대적**으로 확실하며 **필연적으로 참**인 믿음 — 영속적이고 불변하는 대상을 향함
- *윤리적 관점에서는 우연적 참도 가치를 지님*
  > "참인 확신은 행위의 올바름과 관련해서는 앎보다 더 못한 인도자가 결코 아니네."
- 필연적 진리는 감각이 아닌 이성의 직관이나 추리를 통해 이해됨
- 감각을 통해 지각되는 대상은 일시적이고 변화함 — 이로부터는 단지 의견(억견)만 얻어짐

![[Analogy_of_the_Divided_Line.png]]

> "있는 것에는 인식이, 있지 않은 것에는 필연적으로 무지가 상관한다."

인식론에서 존재론으로, 인식 주체에서 인식 대상으로의 전환.

### 보편자 실재론
- 보편자는 비물질적이며, 독립적으로 실재함

### 유명론
- 보편자란 개별자들의 이름뿐이다

### 프로타고라스(상대주의) — 거인
- 본능과 엮여 있어 설득력 있음

## 동굴의 비유

가시계 = 동굴 안, 가지계 = 동굴 밖.

태양에 비친 그림자를 본 이후에야 태양을 인식하게 됨. 빛이 지성적 인식을 가능하게 하는 원리로 작용함.
- 빛 → 인식: 아우구스티누스의 조명설로 연결됨 — 신이 빛으로 어떠한 지식을 내림. 이러한 빛을 인식하기 위해 이성이 필요함
- 중세 이후: "자연의 빛" — 스스로의 인식을 통해 나아감

| | 의견 | | 지식 | |
|---|---|---|---|---|
| 이미지 | 감각대상 | | 수학적 대상 | 이데아 |
| 억측 | 믿음/확신 | | 추론적 사고 | 지성적 앎 |
| 동굴에 비친 그림자 | 동굴 속 불 | | 밖의 인식 대상 | 태양 |

우리는 뒤도 돌아보지 못할 만큼 묶여 있어 그림자만 바라봄. (일반적인 세계에서 바라보는 일반적인 것들은 감각대상까지만 인식하는 게 아닌가?)

**철학자의 과제**: 태양을 지각한 이후 다른 사람들에게 알려야 함. 감각세계에 남아있던 사람들보다 오히려 (다시 동굴로 돌아왔을 때) 적응하기 힘들어할 수 있음. 이러한 철학자들은 비난과 위협의 대상이 됨 (소크라테스의 경우).

**선분의 비유와 동굴의 비유를 연결하기 어려운 지점**: 선분의 비유는 대상에 대한 인지상태의 명확성 정도로 단계를 구분함 — 가시계는 상상/믿음, 가지계는 추론/지성으로 나뉨. 동굴의 비유에서 동굴 안 그림자를 상상에, 동굴 밖 태양을 지성에 대응시키는 것은 명확하지만, **동굴 속을 비추는 불을 어디에 대응시킬지가 해석의 난제**임. 불을 믿음에 대응시키면, 일상생활에서는 가시계 전체를 인식하는 데 비해 동굴 속에서는 그림자만 보게 된다는 비대칭이 생기고, 그렇다고 불을 가지계 쪽으로 해석하면 플라톤이 애초에 동굴 안을 가시계 전체로, 동굴 밖을 가지계 전체로 설정한 구도와 어긋나 보이는 문제가 생김.

## 상기론 — 보편자로 향하는 방법

영혼은 육체와 결합하기 이전의 기억을 가지고 있음. 영혼은 이데아와 근본적으로 다르지 않음 (다만 영혼 자체가 이데아는 아니며, 유사한 존재로 상정 — 영혼 ≠ 보편자).

**문제**: 영혼이 개별적 존재라면 어떻게 보편적 세계에 존재하는가? (플라톤 자신도 명확히 풀지 못한 지점)

- 선천적으로 지식을 가지고 태어남 (본유관념에 가까움) — 노예 소년 예시. 감각지각을 통해서만 지식에 도달하는 것은 아니지만, 감각지각이 계기·촉구가 될 수는 있음
- 상기를 통해 보편자에 도달 → 선천적 지식을 지녔음이 드러남

### 이원론
- 영혼과 육체를 구별 — 영혼은 영원불변하지만 육체는 끊임없이 변화 → 어떻게 상기가 가능한지에 대한 근거로 작용
- 신체가 소멸된 이후 영혼은 지성세계에 머물며 이데아를 인식
- 삶과 죽음의 반복은 영혼이 있음으로써 가능

감각은 이데아에 대한 지식을 방해하는 해로운 것. 철학은 궁극적 지식에 도달하려 함.

> "쾌락과 고통은 못과 같아서 영혼을 육체에 묶이게 한다."

- **감옥의 비유**(육체가 영혼을 어떻게 제한하는가): 육체로부터의 해방에 도달하도록 도와야 하며, 진정한 해방은 죽음으로 나타남. 육체에 의해 영혼이 오염될 경우 보편적 세계를 망각할 수 있음 — 철학은 육체로부터의 해방을 미리 연습하는 것과 같음
- **말과 마부의 비유**
- **배와 선원의 비유** (데카르트가 비유한 플라톤의 이원론): 영혼이 없으면 육체의 움직임이 불가능
