## 1. 마음에 대한 인식

**마음**: 주체와 그의 상태. 마음도 우리에게 인식될 수 있음.

- 마음은 어떻게 나타나는가?
- 마음 개념을 어떻게 가지게 되는가?

**의식은 현상학적 태도**에서 나타나고 **마음은 자연적 태도**에서 나타남 — **의식은 마음의 본질을 이룸**.

**현상학적 심리학**: 자연적 태도에서 세계와 몸을 전제한 채 마음을 탐구하고, 그것의 요소인 의식을 현상학적 반성을 통해 탐구.

- 반성적 자기의식 vs 선반성적 자기의식
- 일상적 마음인식 vs 현상학적 마음인식

## 2. 반성

**반성적 자기의식**
- 반성을 통해 마음을 인식
- 반성은 이미 일어난 의식을 돌아보는 것
- 자료, 작용에 대한 반성적 지각은 그것들이 **이미 구성됨을 전제**
- **명시적, 의도적 혹은 암묵적, 습관적일 수 있음**

**선반성적 자기의식**
- 반성에 앞서 이미 마음을 인식
- 근본적 내적 의식
- **암묵적, 습관적 반성으로부터 구분**

## 3. 마음인식

### 3.1 일상적 마음인식

자연적 태도에서 마음인식 — 자연적 태도에서 마음은 몸과 세계 안에 있는 것으로 나타남.

- 몸 안에 있고 세계로부터 자극을 받고, 행위를 일으킴
- 언제나 몸과 함께 세계를 경험함 — **고유감각 + 외부감각**
- **바깥에서 경험되는 몸에는 안에서 경험되는 몸과 세계가 규칙적으로 결부** → 외부감각 = 고유감각 + 세계
- **우리는 타자의 몸을 경험하면서 그것에 결부되는 고유감각적 성질과 외부감각적 성질을 간접적으로 알 수 있음**
- **경험, 관점의 주체가 구성됨**

세계를 경험할 뿐 아니라 세계에 대해 행위를 함. 행위는 원인을 가짐(의지, 욕구, 습관 등).

- **국소화**: 감각, 감정 등에 몸의 특정한 위치를 부여
- **동기부여**: 자연의 인과와 구별되는 마음의 인과. 우리는 자신이 경험하는 세계에 대해 자신이 어떤 행위를 하는지 알 수 있고, 타자가 경험하는 세계에 대해 그가 어떠한 행위를 하는지 간접적으로 알 수 있음.
- **행위의 주체, 인격의 주체가 구성됨**: 이때 행위의 주체와 인격의 주체는 다른 것. 행위의 주체는 직접 행동을 발현하고, 인격의 주체는 타인의 행동과 동기까지 간접적으로 파악함.

### 3.2 현상학적 마음인식

현상학적 태도에서 마음인식 — 몸과 세계에 대한 인식은 탐구에 사용되지 않음.

- 현상학적 태도에서 남는 것은 순수한 의식과 주체
- **현상들이 일어나는 장이자 법칙인 순수한 주체, 초월적 주체 탐구**
- 후설에 따르면 순수한 의식은 마음에서 본질적인 것

## 4. 자기와 타자

타자를 어떻게 인식하는가? → 안 되면 유아론을 받아들여야 함.

**감정이입** (통각적 전이): 자신의 몸과 타자의 몸의 유사성을 통해 자신의 경험을 타자에게 전이함. 비의도적, 암묵적으로 일어나며, 자기의식과 달리 항상 의심할 수 있음.

타자 인식은 인식의 객관성의 근거 — 자신이 경험하는 세계와 타자들이 경험하는 세계들을 통해 객관적 세계가 구성됨.

- **상호주관성**: 인식은 항상 타자들의 주관도 포함함
