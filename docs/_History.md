# docs/ 최상위 이력

TIL 볼트의 루트. VitePress 설정(`.vitepress/`)과 카테고리별 폴더(`computer/`, `philosophy/`, `club/`, `TOEIC/`, `Certifications/`, `External-Activities/`, `project/`, `Templates/`)로 구성됨.

- 2026년경 여러 세션에 걸쳐 대대적 재정리 진행: 폴더명 영어화, 파일명 `NN-Title-Case.md` 형식 통일, 이미지 `assets/` 서브폴더 정리, 파일별 `Pasted image ####.png` → 설명적 이름으로 교체.
- `TIL-Legacy`(구 저장소)와 OneDrive의 별도 `TIL` 폴더 두 곳에서 철학·컴퓨터공학 콘텐츠를 마이그레이션 후 원본 삭제. `철학`, `CS,CE` 폴더는 원본 보존 지시에 따라 그대로 두고 내용만 가져옴.
