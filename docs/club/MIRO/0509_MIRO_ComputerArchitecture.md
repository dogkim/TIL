## 1. 컴퓨터의 기본 구조

![[MIRO_VonNeumannArchi.png]]

“계산하는 곳(연산 장치)과 기억하는 곳(메모리 장치)이 물리적으로 떨어져 있다”

- **CPU/GPU :** 계산 담당
- **메모리 :** 작업 공간
- **버스 :** 통로

컴퓨터가 어떤 작업을 할 때:
	\[ 메모리에서 데이터를 꺼내 → 버스를 지나 → CPU에서 계산 ]
과정을 1초에도 수십억 번씩 반복

반도체 -> 트렌지스터 -> 논리 게이트 -> 낸드 플래시(SSD, USB, 스마트폰), 레지스터, ALU...

## 1-2. 어디서 들어본 장치들

### **1. 레지스터 (Register)**
레지스터가 있어서 연산도중에도 다른 데이터를 들고 올 수 있음

- **물리적 위치:** CPU 내부 (ALU 인접)
- **작동 속도:** CPU 클럭 사이클과 동기화 (레이턴시 1사이클 미만)
- **기능:** 술·논리 연산의 피연산자 및 결과물, 다음 실행 명령어 주소(PC), 상태 정보(Status)의 실시간 저장

### **2. 캐시 메모리 (Cache / SRAM)**
자주 쓰는 데이터를 미리 CPU에 옮겨둠

- **물리적 위치:** CPU 칩 내부
- **기능:** 참조 국부성에 기반하여 DRAM의 데이터를 복사본으로 보유, CPU와 메모리 간의 속도 차이(Memory Wall) 완화
- **관계:** 모든 SRAM이 캐시는 아니지만, **대부분의 CPU 캐시는 SRAM으로 제작**됨.
### **3. 주기억장치 (Main Memory / DRAM)**
CPU가 직접 소통하는 장치
보조기억장치는 CPU에 비해 속도가 느려서 필요함
낸드 플래시는 열에 영향을 많이 받음. SSD는 CPU의 발열에 취약

- **물리적 위치:** CPU 외부 메인보드 슬롯 (메모리 버스 연결)
- **데이터 성격:** 휘발성, 전원 차단 시 전하 방전으로 데이터 소실
- **기능:** 실행 중인 프로세스의 코드 영역, 데이터 영역, 힙(Heap), 스택(Stack) 상주 공간

### **4. 보조기억장치 (Secondary Storage / SSD·HDD)**
CPU가 직접 접근하지 못함

- **물리적 위치:** 인터페이스를 통한 외부 연결
- **소자 특성:** NAND Flash (SSD) / 자기 디스크 (HDD)
- **데이터 성격:** 비휘발성, 플로팅 게이트나 자성체를 이용한 데이터 영구 보존
- **기능:** 파일 시스템 기반의 데이터 저장, 운영체제(OS) 커널 이미지 및 응용 프로그램 설치 파일 보관

### 중간 정리
CPU-셰프 / DRAM - 준비된 재료 / SSD,HDD - 냉장고 
캐시 - 자주 쓰는 재료 / 레지스터 - 도마, 웍..

## 2. 어떻게 빨라지고 있었나?
___
트렌지스터를 작게 만든다!

트렌지스터:
"**전기 신호를 주면 켜지거나 꺼지는 미세한 스위치이며, 모든 디지털 논리를 실현하는 최소 단위**"

반도체 -> 트렌지스터 -> 논리 게이트 -> 낸드 플래시(SSD, USB, 스마트폰), 레지스터, ALU...

트렌지스터 소형화의 이점
1. 같은 공간에서 더 많은 일을 할 수 있게 된다! (더 많은 코어, 더 큰 캐시)
2. 작아지니까 사용하는 전력소비도 줄어든다! 
3. 전력소비가 줄어드니 트렌지스터당 발열도 줄어든다!

소형화의 제약
1. 트렌지스터가 작아지면서 사이의 벽이 얇아저 전자가 통과해버림
2. 필요한 전압이 낮아지면서 열에너지 때문에 날뛰는 전자로 인해 흐르게 됨

### 2. 병목 현상 (느린 버스, 메모리 속도)
Memory Wall + Von Neumann Bottleneck

CPU는 빠른데,
CPU와 DRAM사이의 속도차이 + DRAM에서 CPU로 메모리를 들고오는 시간이 너무 길다!

왜 차이가 날까?
- **CPU:** 트랜지스터 스위치만 바꾸면 끝
- **DRAM:** 데이터를 읽으려면 커패시터에 든 전기를 빼내야 하고, 쓰려면 다시 채워야 하는데, 트랜지스터를 아무리 줄여도 이 물리적 충전 속도를 CPU의 연산 속도만큼 올리기 힘듦

**결국 CPU가 빨라져도 메모리 속도에 맞춰야한다!**

### 1. HBM (High Bandwidth Memory - 고대역폭 메모리): 

![[MIRO_TSV.png|688]]

DRAM과 CPU사이의 길을 늘리자!

D램을 수직으로 쌓아 올림

**TSV(실리콘 관통 전극)**:
	칩에 미세한 구멍을 뚫어 전극으로 연결

1. 통로의 개수가 늘었다!
2. 수직으로 다니니 경로가 짧아져 전력소모를 줄였다! (발열 문제)
3. CPU와 붙여서 지으니 거리가 짧아져 병목현상을 해결했다!
