# 강의 공부 과정 (1회독)

1회독 진행 방식. 다른 과목에도 같은 순서로 적용한다.

## 1. 자료 준비
- 강의자료를 텍스트로 뽑아 **개조식 정리본**을 만든다.
- **원본 자료와 정리본을 나란히 놓고 같이 보면서** 공부한다.
	- 정리본은 원본 순서대로 쓰고 쪽 번호를 달아 서로 맞춰 보기 쉽게 한다.
- 비어 있는 칸(수업 중 채우는 부분)은 문맥으로 보충하고 표시해 둔다.

## 2. 헷갈리는 개념 하나씩 질문하기
- 정리본을 읽다가 막히는 곳마다 바로 질문한다.
- 한 개념이 이해 안 되면 **더 기초로 내려가서** 다시 묻는다.
	- 예: "이 그래프가 왜 이렇지?" → "y축이 뭐지?" → "그 단위는 어디서 오지?"
- 과제나 다른 장에 적용된 사례가 있으면 **그 사례에 대입해서** 확인한다.

## 3. 정리 파일 저장
- 정리본을 파일로 저장하고, 내가 한 질문과 답을 **Q&A로 붙인다**.

## 4. 큰 흐름 잡기
- 개별 내용을 이해한 뒤 **장 전체의 흐름**을 묻는다. ("이 장은 무엇을 어떤 순서로 쌓아 가나?")
- 개념이 어느 장 소속인지, 사례마다 어떤 도구를 쓰는지 **비교표**로 확인한다.

## 5. 내 말로 요약하고 고치기 (반복)
1. 흐름을 **직접 써서** 보낸다.
2. 틀리거나 애매한 부분을 지적받는다.
3. 막힌 개념은 2단계로 돌아가 다시 질문한다.
4. 고친 요약을 다시 보낸다.
5. 더 고칠 게 없을 때까지 반복한다.

## 6. 마무리
- 완성한 내 요약을 정리 파일 **맨 위**에 넣는다.
- 남은 용어(영어 표현, 정확한 뜻)를 확인한다.

---

> 정리본 + 원본 같이 읽기 → 막히는 개념 질문(기초까지) → 파일 저장(Q&A 포함) → 전체 흐름 잡기 → 내 말로 요약 → 피드백·수정 반복 → 완성본을 파일 맨 위에
