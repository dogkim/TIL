# computer/URA 이력

학부연구생(Undergraduate Research Assistant) 활동 기록. 원래 날짜별 파일이 한 폴더에 섞여 있었으나, "그날그날 정리하는 폴더"와 "결과물이 나올 때마다 정리하는 폴더"를 나누고 싶다는 요청으로 `daily/`(원본 일지, 날짜 유지)와 `results/`(완성된 결과 보고서, 날짜 없이 순번만)로 분리. 처음에는 기존 파일을 통째로 results로 옮겼다가, "일지는 daily에 남기고 results에는 새로 정리한 요약 보고서를 만들어 달라"는 정정을 받아 재작업함.
