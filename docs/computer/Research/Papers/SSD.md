
| **단위**      | **특징**                                                            |
| ----------- | ----------------------------------------------------------------- |
| Page (페이지)  | 읽기와 쓰기(Program)를 수행하는 최소 단위 <br>보통 수 KB(예: 16KB) 크기입니다.           |
| Block (블록)  | 삭제(Erase)를 수행하는 최소 단위<br>수백 개의 페이지가 모여 하나의 블록을 이룹니다.              |
| Plane (플레인) | 여러 개의 블록이 모인 구역<br>독립적인 제어 회로가 있어, 서로 다른 플레인은 동시에 작업을 수행할 수 있습니다. |
| Die (다이)    | 실제 반도체 회로가 그려진 웨이퍼 상의 한 조각<br>독립적인 명령 처리가 가능한 최소 물리적 단위입니다.       |
| Chip (칩)    | 하나 이상의 다이(Die)를 묶어 외부와 통신할 수 있게 만든 완제품(Package)                   |
#### **① Page (페이지)**

- 데이터를 **읽고 쓸 때** 이 단위로 움직입니다.
- 특이한 점은 낸드 플래시 특성상 '덮어쓰기'가 안 된다는 것입니다. 이미 데이터가 써진 페이지에 새 데이터를 넣으려면 블록 전체를 지워야 합니다.
#### **② Block (블록)**

- 데이터를 **지울 때** 사용하는 단위입니다.
- 페이지 단위로 지우지 못하는 이유는 공정 구조상 높은 전압을 가해 전자를 빼내는 작업이 회로적으로 블록 단위로 묶여 있기 때문입니다.
#### **③ Plane (플레인)**

- 하나의 다이(Die) 안에 보통 2개나 4개의 플레인이 있습니다.
- '멀티 플레인 연산'을 통해 성능을 높입니다. 예를 들어 1번 플레인과 2번 플레인에서 동시에 데이터를 읽어 처리 속도를 2배로 만들 수 있습니다.
#### **④ Die (다이)**

- 우리가 흔히 말하는 **'반도체 소자'** 그 자체입니다.
- RiF(Read-Retry) 논문에서 **On-Die**라고 하는 이유는, 외부 컨트롤러를 거치지 않고 이 다이 내부의 로직에서 에러를 판단하고 즉시 해결하겠다는 뜻입니다.

#### **⑤ Chip (칩/Package)**

- 우리가 눈으로 보는 검은색 반도체 덩어리입니다.
- 최신 기술(V-NAND 등)은 용량을 키우기 위해 하나의 칩 안에 여러 개의 다이(Die)를 수직으로 쌓아 올립니다.

#### WL (wordline)
정의: 3D NAND 플래시 메모리 구조에서 수직으로 연결된 여러 개의 플래시 셀들을 하나의 그룹으로 묶어 제어하는 '제어 게이트(control gate)'를 의미합니다.
동작 방식:
같은 수직선 상에 있는 셀들은 공통된 WL을 공유합니다.
WL에 특정 전압을 가하면 해당 WL에 연결된 모든 셀에 동시에 접근하여 데이터를 읽거나 쓸 수 있습니다. 이는 플래시 메모리에서 여러 셀을 한 번에 처리할 수 있게 하는 기본 메커니즘입니다

### 낸드 플래시
바둑판 같은 격자 구조로 되어 있습니다. 이때 가로 방향으로 연결된 선이 바로 **Wordline**입니다.

- **선택(Selection):** 수많은 데이터 셀 중에서 내가 읽거나 쓰고 싶은 '행'을 활성화합니다.
    
- **전압 인가:** 앞서 질문하신 문턱 전압($V_{TH}$)을 체크하기 위해 셀에 읽기 전압이나 쓰기 전압을 전달하는 통로 역할을 합니다.
### 2. Wordline vs. Bitline

데이터를 찾을 때는 가로선과 세로선이 만나는 지점을 찾아야 합니다.

- **Wordline (가로):** 데이터를 읽을 '페이지(Page)' 단위를 결정합니다. "이 줄(Row)을 읽겠다"는 신호를 줍니다.
    
- **Bitline (세로):** 선택된 Wordline 내에서 실제 데이터를 입출력하는 통로입니다. "이 칸의 데이터를 내보내겠다"는 역할을 합니다.
