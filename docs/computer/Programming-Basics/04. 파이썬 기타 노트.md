## 올림·내림·반올림

소수점 둘째 자리까지 계산, 1의 자리에서 반올림 시 `round(tax, -1)`

```python
import math

math.ceil(tax)     # 올림
round(tax, 2)       # 반올림 (소수점 2자리까지)
math.floor(tax)     # 내림
```

## 문자열 메서드

| 메서드 | 설명 | 예시 |
|---|---|---|
| `lower()` | 소문자로 변환 | `"TEST".lower()` → `"test"` |
| `split(sep)` | `sep` 기준으로 분리, 생략 시 공백 기준 | `"2024-04-03".split('-')` → `['2024','04','03']` |
| `strip()` | 문자열 앞뒤 공백 제거 | `"  1234  ".strip()` → `"1234"` |
| `replace(a, b)` | `a`를 `b`로 치환 | `"12,100".replace(",", "")` → `"12100"` |

## dict — items()

```python
car = {"name": "BMW", "price": "7000"}
car.items()
# dict_items([('name', 'BMW'), ('price', '7000')])

for key, val in car.items():
    print("key : {} value : {}".format(key, val))
```
