## 파일 입출력 기초

```python
fp = open("price.txt", "r", encoding="utf-8")
for line in fp:
    item, price = line.split(':')
    print(item.strip(), price.strip())
fp.close()
```

- `open(path, mode, encoding=...)`: 텍스트 파일은 `encoding="utf-8"`을 명시하지 않으면 시스템 기본 인코딩(Windows는 cp949)으로 열려 한글이 깨질 수 있음
- 파일 객체는 `for line in fp:`로 한 줄씩 순회 가능 — `fp.readline()`은 한 줄만, 반복 호출 시 다음 줄로 이동
- 숫자 파싱 시 천단위 콤마(`"1,000"`)는 `str.replace(',', '')` 후 `int()` 변환, 다시 콤마를 넣을 땐 3자리씩 잘라 `','.join()`

```python
result = str1.replace(",", "")
line = str(int(result))
reversed_line = line[::-1]
chunks = [reversed_line[i:i+3] for i in range(0, len(reversed_line), 3)]
formatted = ",".join(chunks)[::-1]   # 천단위 콤마 다시 삽입
```

## itertools로 순열/조합 생성

```python
import itertools

alphabet = "abcdefghijklmnopqrstuvwxyz"
words = []
for length in range(1, 5):
    for combo in itertools.product(alphabet, repeat=length):
        words.append("".join(combo))
words.sort()   # 사전순 정렬 → n번째 단어 찾기 같은 문제에 활용
```

`itertools.product(iterable, repeat=n)`은 **중복을 허용하는 데카르트 곱**(길이 n인 모든 조합, 순서 고려)을 생성 — "사전에서 n번째 단어 찾기" 같은 완전탐색 문제에 자주 쓰임. 이 외 `itertools.permutations`(순열), `itertools.combinations`(조합, 중복 없음)도 같은 패키지에 있음.

## 함수형 도구: map / filter / sorted / reduce

```python
result = list(map(lambda n: -n, [1, -2, -3, 4]))       # 각 원소에 함수 적용
evens = list(filter(lambda n: n > 3, [1, 2, 34, 5, 6])) # 조건을 만족하는 원소만
pairs = list(zip([1, 2, 3], ["one", "two", "three"]))   # 여러 시퀀스를 짝지음

students = [('홍길동', 3.9), ('김철수', 3.0), ('최자영', 4.3)]
by_gpa = sorted(students, key=lambda x: x[1], reverse=True)  # key로 정렬 기준 지정

import functools
total = functools.reduce(lambda x, y: x + y, [1, 2, 3, 4])  # 누적 계산 (좌→우)
```

- `max(lst, key=lst.count)`: `lst.count`를 key 함수로 넘겨 "가장 많이 등장하는 원소"를 바로 찾는 관용구
- `sorted(set(lst))`: 중복 제거 + 정렬을 한 번에 (`sort()`와 `sorted()`의 차이는 [[03. 파이썬 리스트|03. 파이썬 리스트]] 참고)

## 모듈과 표준 라이브러리

```python
import os
print(os.getcwd())          # 현재 작업 디렉터리

import sys
print(sys.prefix)           # 파이썬 설치 경로

import time
now = time.localtime()
print(now.tm_year, now.tm_mon, now.tm_mday)

import calendar
print(calendar.calendar(2025))
```

- `import module`: 모듈 전체를 가져와 `module.func()`로 사용 / `from module import func`: 이름만 가져와 `func()`로 바로 사용 / `import module as alias`: 다른 이름으로 사용(기존 코드의 모듈명과 충돌 회피 등)
- 사용자 정의 모듈(`.py` 파일)을 다른 스크립트에서 `import`하려면, 같은 폴더에 두거나 시스템 환경변수 `PATH`에 해당 폴더를 등록해야 함
- `if __name__ == "__main__":`: 이 스크립트가 **직접 실행될 때만** 아래 코드를 실행 — 다른 파일에서 `import`될 때는 실행되지 않음(모듈로서 함수만 재사용하고 싶을 때 필수 패턴)
