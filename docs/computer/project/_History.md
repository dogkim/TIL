# computer/project 이력

개인 사이드 프로젝트의 "과정/생각의 흐름"만 기록하는 폴더 — 소스코드 자체는 담지 않는다는 원칙(2026-09 세션에 명시적으로 정함). 실제 코드는 각 프로젝트의 원본 위치(예: OneDrive 바탕화면)에 별도 보관.

하위 폴더: `imfoster`(구 오타 표기 "infoster/imposter" — 공지사항·채용정보 자동화 크롤러 프로젝트, 혼자 진행), `Zing`(교환학생 매칭 앱, 김서희와 2인 개발 — 원래 최상위 `docs/project/`에 있던 것을 이 폴더로 이동, 2026-09 세션).

(`Mandu` 폴더는 프로젝트가 진행되지 않아 2026-09 세션에 삭제함.)
