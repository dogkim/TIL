# computer/project/Zing 이력

2인 팀 프로젝트(김도균, 김서희)로 기획 중인 소셜 앱. 해외 교환학생과 한국 학생을 자동 번역으로 이어주는 일기 기반 매칭 서비스 — 랜덤으로 넘겨보는 일기 피드에서 서로 "징(Zing)"을 보내 매칭되면, 그때부터 소통 방식·횟수 제한이 관계 지속 기간에 따라 단계적으로 풀리는 것이 핵심 차별점.

기술 스택: Expo(React Native + react-native-web) + TypeScript + Supabase + 번역(Papago 기본, DeepL 폴백). 김도균은 프론트엔드를 제외한 전반(기획·백엔드·데이터베이스·번역 연동 등)을 맡고 있음.
