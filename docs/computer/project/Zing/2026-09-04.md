### 웹 우선 진행 결정

Expo(React Native + react-native-web) 스택은 유지하되, 앱보다 **웹 타겟을 먼저 완성**하기로 결정. 모바일 앱은 나중에 같은 코드로 빌드.

### 이번 주 목표

"로그인 → 일기 작성 → 피드 넘기기 → 징 보내기"까지 웹에서 눈으로 보이게 만드는 것.

**오늘~내일 (공동, 1~2시간)**
- [ ] **프로젝트 셋업**: `npx create-expo-app` → `npx expo start --web`로 브라우저에서 뜨는지 확인. Supabase 프로젝트 생성.
- [ ] **DB 스키마 확정**: `users`, `diaries`, `zings`, `prompts`, `messages` 테이블 컬럼까지 회의로 못박기. 아직 값이 미정인 정책(동시 매칭 상한, 단계별 소통 규칙)은 필드만 만들어두고 값은 나중에 채움.

**역할 분담 (웹 기준 재정렬)**
- **김도균**: Supabase Auth/RLS, DB 스키마, 징 매칭 로직(백엔드)
- **김서희**: 웹 화면(로그인, 일기 작성 폼, 피드 UI) — react-native-web 위에서

### 이번 주 리스크 체크 (막히면 늦게 발견할수록 손해)

- [ ] **스와이프 카드가 웹에서 되는지**: `react-native-deck-swiper` 계열이 react-native-web에서 잘 안 될 수 있음. 한 명이 15분 스파이크로 먼저 검증 — 안 되면 웹은 버튼(다음/징) 방식으로 단순화.
- [ ] **API 계약(타입)을 먼저 정의**: 백엔드 완성을 기다리지 않고 프론트가 목업 데이터로 먼저 UI를 만들 수 있게. 기존 로드맵의 "피드 UI — 목업 데이터로 먼저 검증"을 첫 스텝으로 당김.

### 이번 주엔 손대지 않기

번역(Papago/DeepL), 채팅, 단계적 소통 해금 규칙 — 로드맵 5~8단계. 미정 정책 논의로 발이 묶이지 않도록 뒤로 미룸.

**우선순위 1번**: 09-03에 김도균 담당으로 배정된 미정 항목(동시 매칭 인원 상한, 소통 해금 단계표, 채팅 범위)을 다음 회의 전까지 결론 내는 것. 이게 늦어지면 DB 스키마 확정도 밀림.

### 저장소 분리

기획 노트는 기존대로 이 TIL repo(public)에 계속 쌓지만, 실제 코드는 별도 **private repo**(`Zing`, 김서희가 생성해 공유)로 분리. 코드/설정은 push로 공유, `.env`(Supabase 키 등)는 각자 로컬에서만 관리하고 커밋하지 않음.

### 초기 셋업 가이드 (스캐폴딩은 한 명만 진행)

**담당자 1명 (최초 1회)**
1. 프로젝트 스캐폴딩
   ```bash
   cd C:\Github\Zing
   npx create-expo-app@latest . --template blank-typescript
   ```
2. 웹 실행 확인: sjrk  → 브라우저에 기본 화면 뜨면 성공
3. 폴더 구조 생성: `screens/`, `components/`, `lib/`
4. 환경변수 세팅: 루트에 `.env` 생성, `.gitignore`에 `.env` 등록 확인
   ```
   EXPO_PUBLIC_SUPABASE_URL=
   EXPO_PUBLIC_SUPABASE_ANON_KEY=
   ```
5. Supabase 연결: 프로젝트 생성 → API 키 `.env`에 채우기 → `npx expo install @supabase/supabase-js` → `lib/supabase.ts`에 클라이언트 초기화 코드 작성
6. 커밋 & push (`.env`는 gitignore로 자동 제외)

**나머지 한 명 (그 다음)**
1. `git pull`
2. `npm install` (스캐폴딩은 이미 되어있으니 라이브러리만)
3. `.env` 파일 직접 생성 — Supabase URL/키는 담당자에게 별도 채널로 전달받아 채움 (절대 커밋 금지)
4. `npx expo start --web`으로 실행 확인

**이후 개발 흐름**: 작업 시작할 때마다 `git pull` → (새 라이브러리 추가됐으면) `npm install` → 개발

**진행 상태**: 김도균이 셋업 및 push 담당 (진행 중).
