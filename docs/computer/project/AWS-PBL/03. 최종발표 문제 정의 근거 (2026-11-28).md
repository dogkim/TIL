# 최종발표 문제 정의 근거 자료

> AWS Career Launchpad PBL 또리(DDORI) 최종발표(2026-11-28) "01 문제 정의"에 쓴 사례와 통계. 숫자는 원문을 직접 열어 확인한 것만 적었고, 덜 확인된 것은 따로 표시했다.

발표에는 두 가지만 썼다.

1. **말이 어려워서 제대로 대처하지 못한다:** 일본 "피난 권고 / 피난 지시" 사례 (4쪽)
2. **재난 때 아이와 떨어진 부모는 불안하다:** 일본 보호자 95.1% (5쪽 "3. 연결" 칸)

## 1. 발표에 쓴 사례

### 1-1. 일본: "피난 권고"를 헷갈려서 그 말을 없앴다

- 2019년 태풍 19호(하기비스) 때 피난 권고가 나와도 대피하지 않거나 늦게 대피한 사람이 많았다.
- 일본 내각부 주민 웹 설문: 태풍 19호로 인명 피해가 난 시정촌의 웹 모니터 3,078명, 2020년 1월
- "피난 권고(避難勧告)"와 "피난 지시(避難指示, 緊急)"의 뜻을 바르게 알았는지

| 응답 | 비율 |
| --- | --- |
| 둘 다 바르게 알았다 | **17.7%** (545명) |
| 피난 권고만 바르게 알았다 | 9.1% (280명) |
| 피난 지시만 바르게 알았다 | 6.8% (209명) |
| 둘 다 틀렸다 | **66.4%** (2,044명) |

- "실제로 언제 대피하겠냐"는 질문: 피난 **지시** 때 대피 40.0%(가장 많음), 대피를 시작해야 하는 피난 **권고** 때 대피 26.4%
- 결과: 2021-05-20 재해대책기본법 개정으로 "피난 권고" 단계를 없애고 "피난 지시" 하나로 합쳤다. 재난문자(긴급속보 메일)뿐 아니라 방송 등 어디서도 "피난 권고"가 나오지 않는다.
- 출처
  - 내각부 「令和元年台風第19号等を踏まえた避難情報及び広域避難等のあり方について（最終とりまとめ）」(2020-12-24), 13~14쪽: https://www.bousai.go.jp/pdf/201224_kouiki.pdf
  - 내각부 워킹그룹 제2회 자료(주민 설문 결과), 11쪽: https://www.bousai.go.jp/fusuigai/typhoonworking/pdf/dai2kai/siryo5.pdf
  - 내각부 개요: https://www.bousai.go.jp/fusuigai/subtyphoonworking/pdf/chukan/gaiyo.pdf
  - 웨더뉴스, 피난 권고 폐지 시행(2021-05): https://weathernews.jp/s/topics/202105/170155/

#### 한국에도 맞는 이유

- 한국 재난문자 표준 문안도 권고와 명령을 나눈다. 산불 대피 **권고** "대피하시기 바랍니다", 산불 대피 **명령** "반드시 대피해주시기 바랍니다".
  - 행정안전부 「재난문자방송 기준 및 운영규정」 [별표 2] 표준문안: https://www.law.go.kr/flDownload.do?bylClsCd=200201&flSeq=149749973
- 대피 명령은 「재난 및 안전관리 기본법」 제40조가 근거이고, 따르지 않으면 과태료(200만 원 이하)와 강제 대피가 있다. 대피 권고는 강제력이 없는 안내 단계다.
  - 설명 글: https://lawscool.co.kr/entry/%EC%9E%AC%EB%82%9C-%EC%8B%9C-%EC%A3%BC%EB%AF%BC%EB%8C%80%ED%94%BC%EC%99%80-%EC%9E%AC%EB%82%9C%EB%AC%B8%EC%9E%90%EC%97%90-%EB%8C%80%ED%95%98%EC%97%AC
  - 주의: 법 조문 원문은 국가법령정보센터에서 직접 확인하지 않았다.
- 정부도 2025년 8월, "안전한 곳으로 대피"처럼 모호한 문자를 언제, 어디로, 어떻게 대피할지 담게 고치기로 했다. 경향신문: https://www.khan.co.kr/article/202508272014015
- 2023년 예천 산사태 때는 산사태가 시작된 뒤에야 대피 문자가 갔고, 강제 대피 명령은 스무 시간 가까이 지나 내려졌다. 이후 산사태 경보가 나면 바로 강제 대피 명령을 내리기로 했다. MBC: https://imnews.imbc.com/replay/2023/nwdesk/article/6505067_36199.html

### 1-2. 일본: 재난 때 아이가 어디 있는지 모르면 보호자 95.1%가 불안하다

- 조사: 明光義塾(메이코 기주쿠), 2026-09-25 ~ 10-02, 인터넷 조사, 초1~고3 자녀를 둔 전국 보호자 1,000명, 2026-10-26 발표
- 재난 때 아이가 어디 있는지 모르는 상황에 불안하다 **95.1%** (매우 불안 61.4%, 조금 불안 33.7%)
- 보호자가 없을 때 재난이 나면 아이 혼자 안전을 지키기 어렵다 **44.5%** (못 할 것 같다 12.2%, 별로 못 할 것 같다 32.3%)
- 스마트폰 위치 정보를 쓰고 있다 35.6%
- 출처: PR TIMES 「子どもがいる家庭の防災に関する実態調査」: https://prtimes.jp/main/html/rd/p/000000338.000071552.html

#### 한국에도 맞는 이유: 아이가 혼자 있는 시간이 많다

- 평일 방과후에 혼자 있는 6~17세 아이 약 **116만 5천 명**, 전체의 20% 이상 (홍나미, 정익중 2019 분석을 인용한 논문)
  - 한국보건사회연구원 「보건사회연구」 41권 2호: https://www.kihasa.re.kr/hswr/v.41/2/178/%EC%B4%88%EB%93%B1+%EB%B0%A9%EA%B3%BC%ED%9B%84%EB%8F%8C%EB%B4%84%EC%84%9C%EB%B9%84%EC%8A%A4+%EC%9D%B4%EC%9A%A9+%EC%9C%A0%ED%98%95%EC%9D%B4+%EB%8F%8C%EB%B4%84+%EA%B3%B5%EB%B0%B1%EC%97%90+%EB%AF%B8%EC%B9%98%EB%8A%94+%EC%98%81%ED%96%A5?view=pubreader
- 2020년 초등학생 학부모 5,050명 중 **23.1%**가 방과후 돌봄이 필요한데 받지 못한다. 맞벌이 가정은 17시 전후에 아이 혼자 있는 비율이 높다.
  - 한국보건사회연구원 보도자료 "방과후돌봄 공백 여전"(2021-06-09): https://www.kihasa.re.kr/news/press/view?seq=36809

## 2. 예비 자료: 아이가 재난 때 제대로 대처하지 못한 설문

### 2-1. 초등학생 241명 지진해일 설문 (초록우산 어린이재단, 2011)

- 헤럴드경제, "초등생 안전교육 문제없나...지진해일 때 가장 안전한 곳은", 2011-03-29: https://mbiz.heraldcorp.com/article/10065794
- 국내 한 초등학교 학생 241명 (일본 대지진 직후)
- 집 근처에 지진해일이 오면 가장 먼저 할 행동: 책상 아래로 숨겠다 65.6% (158명), 건물 밖으로 대피 12.9% (31명). 지진 흔들림 때 요령을 지진해일에 그대로 답했다.
- 가장 안전한 곳: 산 28.6%, 고층건물 옥상 25.7%
- 지진 교육을 받은 적 없음 15.6%
- 주의: 오래된 자료, 학교 한 곳

## 4. 예비 자료: 2023-05-31 서울 경계경보 (뭘 해야 할지 몰랐다)
