# 어린이 재난 대응 앱 비즈니스 모델(BM)

> AWS Career Launchpad PBL 팀 프로젝트. 원본 문서: [Claude Docs](https://claude.ai/artifact/GQAk5mknfgXPq9QPxMfbk5)

재난 대응 기능은 모두 무료로 두고, 돈은 보호자 구독·기관·제휴에서 번다. 아이에게는 결제나 광고를 띄우지 않는다.

## 무료 vs 유료

| 기능 | 무료 | 패밀리 플랜 (월 2,900원) |
| --- | --- | --- |
| 재난 대응 (쉬운 말 문자, 행동 카드, 괜찮아요/도와줘요) | O | O |
| 연결 인원 | 아이 1명 + 보호자 1명 | 여러 명 (조부모·돌봄 선생님 포함) |
| 훈련 콘텐츠 | 지진·화재 | 듀오링고식 전체 코스 (매일 미션, 연속 훈련 스트릭, 대원 등급) |
| 보호자 리포트 | 응답 기록 | 훈련 진도 + 가족 비상 계획서 |

## 수익원

| 고객 | 파는 것 |
| --- | --- |
| 보호자 | 패밀리 플랜 구독 |
| 학교·유치원 | 반 단위 훈련 + 교사용 안전 확인 화면 (연간 라이선스) |
| 지자체 | 관내 초등학생 무료 배포 사업 |
| 통신사·보험사 | 키즈폰·어린이보험 부가서비스 제휴 |

## 차별점

- **정부 재난문자**는 어른 말투다. 우리는 아이 눈높이로 바꾼다.
- **자녀 관리 앱**은 사용 시간·위치 통제가 중심이다. 우리는 재난 순간의 행동과 보호자 연결에 집중한다.
- **학교 안전 교육**은 일회성이다. 우리는 평소 훈련과 실제 대응이 한 앱에서 이어진다.
- **게임형 안전교육 앱**([BabyBus 지진안전교육](https://apps.apple.com/us/app/%EC%A7%80%EC%A7%84%EC%95%88%EC%A0%84%EA%B5%90%EC%9C%A1-%EC%96%B4%EB%A6%B0%EC%9D%B4-%EC%95%88%EC%A0%84/id1160733919?l=ko), 적십자 [Monster Guard](https://www.slj.com/story/prepare-kids-for-emergencies-with-monster-guard))은 교육만 한다. 우리는 실제 재난문자 수신과 보호자 연결까지 이어진다.

## 확인 필요

- 가격 근거: 보호자 설문으로 검증
- 학교 재난안전 교육 의무 기준 (교육부 자료)
