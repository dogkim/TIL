### 1. 시스템 아키텍처 및 기능 요건

#### ① 수집 레이어 (Data Collection)

- **정기 크롤링 (Scheduled):**
    
    - 정적 페이지 (경북대 컴퓨터학부 공지 등): `requests` + `BeautifulSoup` 사용 (가볍고 빠름)
        
    - 동적 SPA 페이지 (링커리어, 슥삭 등): `Playwright` 사용 (JavaScript 렌더링 대응)
        
- **키워드 모니터링 (Event-driven):**
    
    - 잡코리아, 사람인 등 대형 플랫폼의 비정기 이벤트(예: 바이브톤 해커톤) 포착용
        
    - 네이버 뉴스 API 활용 ("해커톤", "공모전" 키워드) 및 주요 공지사항 페이지 변화 감지 기법 적용
        

#### ② 백엔드 & 데이터베이스 레이어 (Backend & DB)

- **프레임워크:** Python `FastAPI` (빠른 API 개발 및 JWT 템플릿 풍부)
    
- **데이터베이스:** `PostgreSQL` (Supabase 또는 Railway 무료 플랜 활용 가능)
    
- **주요 로직:**
    
    - **중복 제거:** 공고 URL 및 제목의 해시(Hash)값을 비교하여 무중단 중복 필터링
        
    - **데이터 정규화:** 다양한 날짜 형식(`07/01`, `2026.07.01`, `상시채용`)을 `YYYY-MM-DD` 규격으로 통일
        
    - **인증 및 개인화:** JWT 기반 회원가입/로그인 구현, 유저별 구독 사이트 및 카테고리(공모전, 인턴, 교육) 설정 저장
        

#### ③ 프론트엔드 레이어 (Frontend UI)

- **프레임워크:** `React` + `TanStack Query` (상태 관리 및 API 동기화 효율화)
    
- **주요 화면:**
    
    - 공고 피드 (카테고리 필터, 마감일 순 정렬)
        
    - 개인 구독 설정 페이지 (알림을 받을 사이트 및 주기 선택)
        
    - 북마크 모아보기 화면
        

#### ④ 알림 및 외부 연동 레이어 (Notification)

- **이메일 알림:** `SendGrid` 무료 플랜 등을 활용하여 구독 정보 발송
    
- **디스코드 봇 (`discord.py`):**
    
    - **단일 봇 다중 채널:** 봇 하나로 카테고리별(공모전, 인턴, 학교공지 등) 디스코드 채널에 알림 분기 발송
        
    - **상호 연동:** 디스코드 메시지에 특정 이모지(★) 반응 시, 백엔드 API를 호출하여 웹 데이터베이스의 유저 북마크에 자동 저장

### 2. 단계별 개발 로드맵

- **1단계 [웹 서비스 구축]:** 크롤러 개발 ➔ DB 설계 및 중복 제거 로직 구현 ➔ FastAPI 백엔드 API(인증 포함) 개발 ➔ React 웹 UI 연동
    
- **2단계 [디스코드 연동]:** 디스코드 봇 서버 추가 ➔ 웹훅(Webhook) 및 API 연동을 통한 실시간 알림 및 이모지 반응 북마크 기능 구현
    
- **3단계 [AI 파서 자동화]:** Gemini API 연동 프롬프트 엔지니어링 ➔ HTML 소스 입력 시 CSS Selector 추출 및 BeautifulSoup 파싱 스크립트 동적 생성 기능 추가
