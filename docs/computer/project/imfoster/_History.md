# computer/project/imfoster 이력

공지사항·채용정보 자동화 크롤러 프로젝트("infoster")의 개발 과정 기록. 01: 만들게 된 계기(4학년 취업 준비 중 기존 자동화 툴의 한계 체감). 02: 웹 스크래핑/HTML 이해. 03: 시스템 아키텍처(FastAPI + PostgreSQL + React + Discord 봇)와 단계별 개발 로드맵.

실제 소스코드(`base.py`, `campuspick.py`, `knu_notice.py`, `models.py` 등)는 TIL에 넣지 않는다는 원칙에 따라 OneDrive 바탕화면의 `project/infoster/` 폴더에만 보관 — 이 문서들은 그 폴더에도 사본이 함께 있음.
