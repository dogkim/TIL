## 1. 주의사항

### Robots.txt의 개념과 경로
- **정의**: 웹사이트 소유자가 검색 엔진 로봇이나 크롤러 같은 자동화 프로그램에게 "이 시스템의 특정 경로에는 접근해도 된다/안 된다"를 알려주는 일종의 규약 문서
    
- **경로**: 루트 디렉토리에 배치하는 것이 표준이므로, 도메인 뒤에 `/robots.txt`를 붙여 확인

**지정어(Directive) 상세 분석**
네이버의 예시 코드
https://www.naver.com/robots.txt
```
User-agent: *
Disallow: /
Allow : /$
Allow : /.well-known/privacy-sandbox-attestations.json
```

- **User-agent**: 크롤링을 수행하는 프로그램(봇)의 이름을 지정
    - 가령 `*` (애스터리스크)는 모든 웹 크롤러를 대상으로 동일한 규칙을 적용하겠다는 의미

- **Disallow: /**: 웹사이트의 루트(`/`) 이하 모든 하위 경로에 대한 크롤링을 기본적으로 금지(Disallow)한다는 선언
    
- Allow: 모든 경로를 막았으나, 메인 페이지(`/$`에서 `$`는 정규표현식으로 '끝'을 의미하므로 정확히 메인 URL 자체)만은 예외적으로 수집을 허용한다는 의미
    
- **Allow: /.well-known/...**: 특정 인증 또는 개인정보 보호 규격 관련 파일이 위치한 경로만 추가로 예외 허용함을 의미
### 수집 및 관리 시 핵심 주의 사항

- **서버 과부하 방지 (Rate Limiting)**
    - 단시간 내의 대량 요청은 웹 서버에 DDoS 공격과 유사한 부하를 주어 IP 차단을 유발할 수 있음
    - 지연 시간을 요청 사이에 강제 삽입하여 서버를 보호해야 함

- **데이터 관리 및 법적 준수 (Compliance)**
    - 공개된 웹페이지라 하더라도 작성자의 이름, 전화번호, 이메일, 학번 등의 개인정보를 대량으로 수집·저장·유포하는 행위는 개인정보 보호법 위반 소지가 있음
    - 수집 데이터는 목적 달성 후 안전하게 파기하거나, 식별할 수 없도록 비식별화 처리를 해야 함

## 2. 웹 크롤링 vs 웹 스크래핑

인터넷에서 자동으로 데이터를 수집하는 방식

- **웹 크롤링 (Crawling)**:
	 웹 사이트를 순회하면서 대규모의 데이터를 수집하는 과정
    - **목적**: 웹사이트의 전체 구조를 파악하고 대규모 데이터를 수집하여 색인(Index)화.
    - **특징**: 검색엔진(구글, 네이버 등)의 '봇/스파이더'가 링크를 타고 돌아다니며 웹 페이지 간의 관계를 맵핑하고 DB에 저장하는 방식.
        
- **웹 스크래핑 (Scraping)**
    특정 웹 페이지에서 필요한 데이터를 추출하는 과정
    
    - **목적**: 특정 웹페이지에서 우리가 원하는 **특정 정보만 추출**.

웹 크롤링이 대규모로 웹 사이트의 모든 정보를 가져와 많은 양의 데이터와 링크를 처리한다면, 웹 스크래핑은 보다 특정적이고, 필요한 데이터만을 추출

### 2. 정적 웹페이지 vs 동적 웹페이지

데이터를 처리하고 화면에 보여주는 방식의 차이로 인해 수집 접근법이 완전히 달라집니다.

- **정적 웹페이지 (Static)**
    
    - **동작**: 서버에 미리 저장된 HTML 파일을 그대로 사용자에게 전달. 모든 사용자가 상호작용 없이 동일한 화면을 봄.
        
    - **장단점**: 로딩이 빠르고 서버 부하가 적으나, 실시간 업데이트나 사용자 맞춤형 서비스가 어려움.
        
    - **데이터 추출**: **페이지 소스코드** 내에 수집하려는 실데이터가 텍스트 형태로 그대로 포함되어 있어 직접 읽기 가능.
        
- **동적 웹페이지 (Dynamic)**
    
    - **동작**: 사용자의 요청이나 입력에 따라 서버 사이드 스크립트 또는 클라이언트 사이드 스크립트(JavaScript)가 실시간으로 콘텐츠를 생성 및 업데이트.
        
    - **장단점**: 사용자 맞춤형 콘텐츠 제공 및 실시간 상호작용이 가능하나, 로딩 시간이 더 걸리고 서버 부하가 큼.
        
    - **데이터 추출**: 초기 소스코드만으로는 데이터를 볼 수 없는 경우가 많음. 자바스크립트가 실행되면서 데이터를 로드하는 과정을 포착해야 함.
        

### 3. 스크래핑 핵심 도구 및 개념

- **파싱 (Parsing)**: 가공되지 않은 HTML/XML 문서 덩어리를 컴퓨터가 분석하기 쉬운 형태로 분해하고 변환하여 원하는 태그나 속성을 쉽게 찾도록 만드는 작업.
    

|**도구**|**주요 타겟**|**작동 방식 및 특징**|
|---|---|---|
|**BeautifulSoup**|정적 웹페이지|- HTML/XML 파싱 전문 라이브러리.<br><br>  <br><br>- 가져온 웹페이지 소스코드에서 원하는 데이터가 들어있는 태그를 신속하게 탐색 및 추출.|
|**Selenium**|동적 웹페이지|- 웹 브라우저 자동화/제어 도구.<br><br>  <br><br>- 마우스 클릭, 키보드 입력, 스크롤 등 사람의 행동을 코드로 자동화하여 자바스크립트가 실행된 최종 화면의 동적 데이터를 포착.|
