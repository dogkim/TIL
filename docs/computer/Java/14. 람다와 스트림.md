## 함수형 프로그래밍의 등장

Java SE 8 이전까지는 절차적·객체지향·제네릭 프로그래밍을 지원했고, Java SE 8부터 **함수형 프로그래밍**이 추가됨(Project Lambda).

- **외부 반복(external iteration)**: 루프로 컬렉션을 직접 순회 — 원소를 순차적으로 접근해야 하고 가변 변수가 필요
- **내부 반복(internal iteration)**: "무엇을 할지"만 지정하고, "어떻게 순회할지"는 라이브러리에 맡김 — 병렬화하기 더 쉬움. 함수형 프로그래밍은 **불변성(immutability)**(데이터 소스나 프로그램 상태를 변경하지 않음)에 초점을 둠

## 함수형 인터페이스 (Functional Interface)

**단일 추상 메서드(SAM, Single Abstract Method)**만 가진 인터페이스 — `java.util.function` 패키지에 6가지 기본 함수형 인터페이스가 있음:

| 인터페이스 | 메서드 | 용도 |
|---|---|---|
| `Function<T,R>` | `R apply(T t)` | T를 받아 R을 반환 |
| `Predicate<T>` | `boolean test(T t)` | 조건 판별 |
| `Consumer<T>` | `void accept(T t)` | 값을 소비(반환 없음) |
| `Supplier<T>` | `T get()` | 값을 공급 |
| `UnaryOperator<T>` | `T apply(T t)` | 같은 타입 변환 |
| `BinaryOperator<T>` | `T apply(T t1, T t2)` | 같은 타입 두 값 결합 |

## 람다 표현식 (Lambda Expression)

함수형 인터페이스를 구현하는 **익명 메서드**의 축약 표기법. `(매개변수목록) -> { 본문 }` 형태.

```java
(int x, int y) -> { return x + y; }   // 완전한 형태
(x, y) -> { return x + y; }           // 매개변수 타입 생략 (문맥으로 추론)
(x, y) -> x + y                       // 본문이 표현식 하나면 중괄호·return 생략, 값이 암묵적으로 반환됨
value -> System.out.println(value)    // 매개변수가 하나면 괄호도 생략 가능
() -> System.out.println("Hi")        // 매개변수가 없으면 빈 괄호
```

**메서드 참조(method reference)**: 람다를 더 축약한 표기법 — 이미 존재하는 메서드를 그대로 참조.
```java
list.forEach(System.out::println);   // value -> System.out.println(value) 와 동일
```

## 스트림 (Stream)

`java.util.stream` 패키지의 `Stream` 인터페이스 — 함수형 프로그래밍 작업을 수행하게 해줌. 여러 처리 단계를 잇는 **스트림 파이프라인(stream pipeline)**을 구성: 데이터 소스로 시작 → 여러 **중간 연산(intermediate operation)** → **최종 연산(terminal operation)**으로 마무리.

- 스트림은 자체 저장공간이 없음 — 한 번 처리하면 재사용 불가(원본 데이터의 사본을 유지하지 않음)
- **중간 연산은 게으르다(lazy)**: 최종 연산이 호출되기 전까지 실제로 수행되지 않음 (라이브러리가 성능을 최적화할 여지를 줌)
- **최종 연산은 즉시 실행된다(eager)**: 호출되는 순간 파이프라인 전체가 처리되고 결과를 만들어냄

```java
List<String> names = Arrays.asList("Kim", "Lee", "Park", "Choi");

names.stream()
     .filter(name -> name.length() > 3)   // 중간 연산: 조건에 맞는 것만
     .map(String::toUpperCase)             // 중간 연산: 변환
     .sorted()                             // 중간 연산: 정렬
     .forEach(System.out::println);        // 최종 연산: 각 원소에 대해 실행
```

**대표적인 중간 연산**: `filter`, `map`, `sorted`, `distinct`, `limit`
**대표적인 최종 연산**: `forEach`, `collect`, `count`, `reduce`, `sum`, `min`/`max`

```java
int total = numbers.stream().mapToInt(Integer::intValue).sum();
List<String> upper = names.stream().map(String::toUpperCase).collect(Collectors.toList());
```

이러한 스트림 기반 코드는 [[13. 제네릭 컬렉션|13장의 컬렉션]] 예제들을 훨씬 간결하게, 그리고 멀티코어 환경에서 병렬화하기 쉬운 형태로(`parallelStream()`) 다시 작성할 수 있게 해줌.
