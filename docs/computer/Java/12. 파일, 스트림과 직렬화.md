## 파일과 영속 데이터

변수·배열에 저장된 데이터는 **임시적(temporary)** — 프로그램이 종료되면 사라짐. 장기 보관이 필요한 데이터는 보조기억장치(하드디스크, SSD 등)의 **파일**에 저장하며, 이렇게 프로그램 실행 기간을 넘어 존재하는 데이터를 **영속 데이터(persistent data)**라 함.

## 데이터 계층

비트 → 문자(바이트) → **필드** → **레코드**(관련 필드들의 묶음) → **파일**(관련 레코드들의 묶음) → **데이터베이스**(관련 파일들의 묶음). 레코드를 식별하는 필드를 **레코드 키(record key)**라 하며, 레코드 키 순서로 저장된 파일을 **순차 파일(sequential file)**이라 함.

## 스트림(Stream)

Java는 모든 파일을 바이트의 **순차 스트림**으로 취급함.
- **바이트 기반 스트림**: 데이터를 이진 형식 그대로 입출력 — 결과물이 **이진 파일(binary file)**
- **문자 기반 스트림**: 데이터를 문자 시퀀스로 입출력 — 결과물이 **텍스트 파일(text file)**, 텍스트 에디터로 열람 가능

Java 프로그램 시작 시 자동으로 생성되는 3개의 표준 스트림:
- `System.in`: 표준 입력(보통 키보드)
- `System.out`: 표준 출력(보통 화면)
- `System.err`: 표준 에러(보통 화면, 에러 메시지용)

파일 처리는 `java.io`, `java.nio` 패키지의 클래스로 수행. `Scanner`(문자 기반 입력, 키보드뿐 아니라 파일도 읽을 수 있음)와 `Formatter`(printf와 유사한 형식화 출력)가 대표적.

## 텍스트 파일 읽고 쓰기

```java
// 쓰기
try (PrintWriter writer = new PrintWriter(new FileWriter("data.txt"))) {
    writer.println("Hello, file!");
}

// 읽기
try (Scanner scanner = new Scanner(new File("data.txt"))) {
    while (scanner.hasNextLine()) {
        System.out.println(scanner.nextLine());
    }
}
```

**try-with-resources**: `try(...)` 괄호 안에서 연 자원(`AutoCloseable` 구현체)은 블록이 끝날 때 자동으로 `close()`가 호출됨 — `finally`에서 수동으로 닫아줄 필요가 없어짐.

## 객체 직렬화 (Object Serialization)

객체를 통째로 바이트 스트림으로 변환해 파일에 저장(또는 네트워크로 전송)하고, 나중에 그대로 복원하는 기능.

```java
public class Person implements Serializable {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

// 저장
try (ObjectOutputStream out = new ObjectOutputStream(new FileOutputStream("person.ser"))) {
    out.writeObject(new Person("Kim", 20));
}

// 복원
try (ObjectInputStream in = new ObjectInputStream(new FileInputStream("person.ser"))) {
    Person p = (Person) in.readObject();
}
```

- 직렬화하려는 클래스는 `Serializable` 인터페이스(마커 인터페이스 — 메서드 없음)를 구현해야 함
- `transient` 키워드를 붙인 필드는 직렬화 대상에서 제외됨
