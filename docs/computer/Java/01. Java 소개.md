## Java란

Java는 세계에서 가장 널리 쓰이는 프로그래밍 언어 중 하나로, **객체지향 프로그래밍(OOP)**을 핵심 방법론으로 채택한다. 기업용 소프트웨어, 인터넷 기반 애플리케이션, 안드로이드 앱 등에 광범위하게 쓰인다.

**Java 에디션**
- **Java SE (Standard Edition)**: 범용 크로스플랫폼 애플리케이션 개발용
- **Java EE (Enterprise Edition)**: 대규모 분산 네트워킹/웹 애플리케이션용
- **Java ME (Micro Edition)**: 메모리 제약이 큰 소형 기기용

## 프로그래밍 언어의 계층

- **기계어(Machine Language)**: 컴퓨터가 직접 이해하는 유일한 언어. 0과 1의 문자열, 기계 종속적
- **어셈블리어(Assembly Language)**: 기계어 연산을 영어 약어로 표현. **어셈블러**가 기계어로 변환
- **고급 언어(High-Level Language)**: 하나의 문장이 상당한 작업을 수행. **컴파일러**가 기계어로 변환하거나, **인터프리터**가 직접 실행

## 객체지향 개념 (자동차 비유)

- **클래스(Class)**: 객체가 수행할 메서드들의 집합을 담는 프로그램 단위 (자동차의 설계도)
- **객체(Object) / 인스턴스(Instance)**: 클래스로부터 만들어진 실체 (설계도로 만든 실제 자동차)
- **메서드(Method)**: 작업을 수행하는 코드를 담고 있으며, 그 세부 구현을 사용자로부터 숨김 (가속 페달 — 내부 메커니즘을 몰라도 밟기만 하면 됨)
- **속성(Attribute) / 인스턴스 변수**: 객체가 가지는 상태 (자동차의 색상, 연료량 등). 각 객체는 자신만의 속성값을 가짐
- **캡슐화(Encapsulation)**: 속성과 메서드를 객체 안에 감싸고, 구현 세부사항을 객체 내부에 숨김 (**정보 은닉**)
- **재사용(Reuse)**: 하나의 클래스를 여러 번 재사용해 여러 객체를 만들 수 있음 — 검증된 클래스를 재사용하면 개발 시간 단축 + 신뢰성 향상
- **메시지 전달**: 객체에게 메시지를 보내는 것은 곧 그 객체의 메서드를 호출하는 것으로 구현됨 (가속 페달을 밟는 것 = "더 빨리 가라"는 메시지)
- **상속(Inheritance)**: 기존 클래스의 특성을 물려받아 새 클래스를 빠르게 만드는 방법 (컨버터블은 자동차의 한 종류지만, 지붕을 열고 닫는 고유 기능이 추가됨)

**객체지향 분석/설계(OOAD)**: 코드를 작성하기 전에 요구사항 분석(무엇을 해야 하는가)과 설계(어떻게 할 것인가)를 먼저 수행. **UML(Unified Modeling Language)**은 객체지향 시스템을 모델링하는 데 가장 널리 쓰이는 그래픽 표기법.

## Java 프로그램 실행 과정 (5단계)

1. **편집(Edit)**: 에디터로 소스코드 작성, `.java` 확장자로 저장
2. **컴파일(Compile)**: `javac Welcome.java` — 컴파일러가 소스코드를 **바이트코드**로 변환해 `.class` 파일 생성 (플랫폼 독립적)
3. **로드(Load)**: JVM(Java Virtual Machine)이 클래스 로더를 통해 `.class` 파일을 메모리로 적재
4. **검증(Verify)**: 바이트코드 검증기가 바이트코드의 유효성과 보안 규칙 위반 여부를 검사
5. **실행(Execute)**: JVM이 바이트코드를 실행 — 인터프리터 방식과 **JIT(Just-In-Time) 컴파일**을 함께 사용해 성능 향상

**JVM(Java Virtual Machine)**: 가상 머신(VM) — 컴퓨터를 소프트웨어로 시뮬레이션. 동일한 JVM이 여러 플랫폼에 구현되어 있으면, 그 위에서 실행되는 프로그램은 플랫폼 독립적으로 동작함 ("Write Once, Run Anywhere"의 근거).

**Java 클래스 라이브러리(Java API)**: 재사용 가능한 클래스·메서드의 모음. 패키지(package) 단위로 그룹화되어 있음.
