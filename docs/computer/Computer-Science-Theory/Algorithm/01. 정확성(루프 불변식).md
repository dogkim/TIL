## 루프 불변식(Loop Invariant)이란

루프의 **매 반복이 시작되기 전과 후에 항상 참인 성질**. 이 성질을 이용해 루프 기반 알고리즘이 올바르게 동작함을 증명하는 기법이 **루프 불변식을 이용한 정확성 증명**이다.

수학적 귀납법과 구조가 같다 — 초기 조건이 참임을 보이고(초기화), 한 단계가 참이면 다음 단계도 참임을 보인 뒤(유지), 마지막에 원하는 결론을 얻는다(종료).

## 증명을 위한 3가지 요건

| 요건 | 영문 | 확인할 내용 |
|---|---|---|
| 1. 초기화 | Initialization | 루프의 **첫 번째 반복을 시작하기 전**에 불변식이 참인가? |
| 2. 유지 | Maintenance | 어떤 반복 시작 전에 불변식이 참이면, **다음 반복 시작 전**에도 참으로 유지되는가? |
| 3. 종료 | Termination | 루프가 종료됐을 때, 불변식이 **알고리즘의 정확성을 보이는 데 유용한 성질**을 알려주는가? |

세 요건이 모두 성립하면, 루프는 항상 의도한 목적을 달성하고 종료된다.

## 예시 — Insertion Sort

**불변식 정의**: 루프의 각 반복이 시작될 때, 하위 배열 $A[1 \dots j-1]$은 **정렬된 상태**이다.

**1. 초기화**
$j=2$일 때 루프가 시작되므로, 하위 배열 $A[1 \dots 1]$은 요소가 하나뿐이다. 요소가 하나인 배열은 항상 정렬되어 있으므로 불변식은 **참**.

**2. 유지**
$A[1 \dots j-1]$이 정렬된 상태라면, 루프 내부에서 $A[j]$를 적절한 위치에 삽입해 $A[1 \dots j]$를 정렬된 상태로 만든다. $j$가 증가해 다음 반복으로 넘어가도 이 성질은 **유지**된다.

**3. 종료**
$j$가 $n+1$이 되어 루프가 종료되면, 불변식에 의해 하위 배열 $A[1 \dots n]$이 정렬된 상태로 종료된다 — 즉 전체 배열이 정렬된 채로 종료된다.
