## Greedy Algorithm이란

매 단계에서 **지금 당장 가장 좋아 보이는 선택**을 하고, 그 선택을 절대 번복하지 않는 방식. 항상 최적해를 보장하지는 않지만, 문제가 특정 구조(그리디 선택 속성 + 최적 부분구조)를 만족하면 최적해를 보장함.

## Activity Selection

시작/종료 시간이 주어진 여러 활동 중, 서로 겹치지 않게 **최대한 많은 활동**을 선택하는 문제.

**그리디 전략**: 종료 시간(finish time)이 가장 빠른 활동부터 순서대로, 이전에 선택한 활동과 겹치지 않으면 선택.

**Time**: 이미 종료 시간 기준으로 정렬되어 있으면 $O(n)$, 아니면 정렬 비용 포함 $O(n\log n)$.

**Correctness (교환 논증, exchange argument)**
- $t$번째 활동까지 선택한 상태에서, 이 선택을 포함하는 최적해 $T^*$가 존재한다고 가정 (귀납 가정)
- 알고리즘이 다음으로 선택한 활동을 $a_k$라 하자
  - $a_k \in T^*$이면: 선택을 포함한 최적해가 그대로 존재
  - $a_k \notin T^*$이면: $T^*$에서 (그리디가 고른 $a_i$ 다음의) 활동을 $a_j$라 하면, $a_k$의 종료 시간이 $a_j$보다 빠르거나 같으므로(그리디가 종료시간이 가장 빠른 것을 골랐으므로) $a_j$를 $a_k$로 바꿔도 이후 활동들과 겹치지 않음 → 활동 개수는 그대로 유지되면서 $a_k$를 포함하는 최적해로 바꿀 수 있음
- 따라서 그리디 선택을 포함하는 최적해가 항상 존재 → 귀납적으로 그리디 알고리즘 전체가 최적

## Huffman Coding

문자별 등장 빈도가 다를 때, 자주 등장하는 문자에 짧은 비트열을, 드물게 등장하는 문자에 긴 비트열을 배정해 전체 인코딩 길이를 최소화하는 **접두 부호(prefix code)**.

**알고리즘**
1. 각 문자를 빈도값을 가진 리프 노드로 하는 min-priority queue 구성
2. 빈도가 가장 작은 두 노드를 꺼내, 그 둘을 자식으로 하고 빈도의 합을 값으로 갖는 새 노드를 만들어 다시 큐에 삽입
3. 큐에 노드가 하나만 남을 때까지 반복 — 이 마지막 노드가 허프만 트리의 루트

**Time**: 우선순위 큐(min-heap) 사용 시 $O(n\log n)$ ($n$: 문자 종류 수)

**그리디 선택 속성**: 빈도가 가장 작은 두 문자는 항상 허프만 트리에서 가장 깊은 곳(형제 리프)에 위치하는 최적해가 존재함 — 이를 교환 논증으로 증명할 수 있고, 이로부터 최적 부분구조(두 문자를 합친 축소 문제의 최적해 + 두 문자를 합치는 선택 = 원래 문제의 최적해)가 성립.

## Prim's Algorithm (최소 신장 트리, MST)

하나의 정점에서 시작해, 현재까지 만든 트리에 **가장 싸게 연결할 수 있는 간선**을 매번 하나씩 추가해 트리를 키워나가는 방식.

**알고리즘**
1. 임의의 시작 정점을 트리에 포함, 나머지 정점의 key 값을 $\infty$로 초기화
2. 트리에 아직 포함되지 않은 정점 중 key 값이 가장 작은 정점 $u$를 선택해 트리에 추가
3. $u$의 인접 정점들에 대해, $u$를 거쳐 연결되는 간선의 가중치가 현재 key 값보다 작으면 갱신
4. 모든 정점이 트리에 포함될 때까지 2~3 반복

**Time**: 배열 사용 시 $O(n^2)$, 최소 힙(binary heap) 사용 시 $O((n+m)\log n)$ — Dijkstra와 구조적으로 거의 동일 (다만 key 값을 "시작점까지의 거리"가 아니라 "트리까지의 최소 간선 가중치"로 정의한다는 차이)

**Cut property (그리디의 정당성 근거)**: 그래프를 두 부분으로 나누는 어떤 cut에 대해, 그 cut을 가로지르는 간선 중 가중치가 가장 작은 간선은 반드시 어떤 MST에 포함됨 — Prim은 매 단계 (트리 vs 트리 밖) cut에서 이 성질을 이용해 안전하게 간선을 선택.

## 보강 — Huffman Coding 최적성의 형식적 증명

위의 "그리디 선택 속성"을 교환 논증으로 조금 더 formal하게 전개하면 다음과 같다.

**Lemma 1 (최소 빈도 두 문자는 형제)**: $x, y$가 빈도가 가장 작은 두 문자라면, $x$와 $y$가 형제(같은 부모의 자식)인 최적 트리가 존재한다.

**증명**: 어떤 최적 트리에서 가장 깊은 레벨의 형제 노드 쌍 $(a, b)$를 생각하자(트리 구조상 가장 깊은 곳에는 반드시 형제 쌍이 존재). 이 중 적어도 하나(예: $a$)는 $x$도 $y$도 아닐 수 있다. 이때 $a$의 빈도는 $x$의 빈도 이상이면서($x, y$가 최소 빈도이므로), $a$가 $x$보다 깊거나 같은 위치에 있다. $x$와 $a$의 위치를 서로 바꾸면:
- $a$(빈도가 더 크거나 같음)는 더 얕은 곳으로, $x$(빈도가 더 작거나 같음)는 더 깊은 곳으로 이동
- 비용 $\sum P(x)\cdot depth(x)$는 **증가하지 않는다** (빈도가 큰 문자를 더 얕게, 빈도가 작은 문자를 더 깊게 보냈으므로)

이 과정을 반복하면 비용을 늘리지 않으면서 $x, y$를 형제로 만든 트리를 얻을 수 있고, 원래 트리가 최적이었으므로 이 트리도 여전히 최적이다.

**Lemma 2 (귀납적 최적성)**: 알파벳 $C$에서 최소 빈도 두 문자 $x, y$를 하나의 문자 $z$(빈도 $= x.freq + y.freq$)로 합친 알파벳을 $C'$라 하자. $T'$가 $C'$에 대한 최적 트리라면, $T'$에서 리프 $z$를 $x, y$를 자식으로 갖는 내부 노드로 바꾼 트리 $T$는 $C$에 대한 최적 트리다.

**증명**: $x, y$의 깊이는 $T$에서 $z$의 깊이보다 정확히 1 크므로 ($d_T(x) = d_T(y) = d_{T'}(z) + 1$),

$$x.freq \cdot d_T(x) + y.freq \cdot d_T(y) = (x.freq+y.freq)(d_{T'}(z)+1) = z.freq \cdot d_{T'}(z) + (x.freq+y.freq)$$

이므로 $\text{Cost}(T) = \text{Cost}(T') + x.freq + y.freq$. 이제 $T$가 최적이 아니라고 가정(귀류법)하면, $\text{Cost}(T'') < \text{Cost}(T)$인 트리 $T''$가 존재한다. Lemma 1에 의해 $T''$에서도 $x, y$를 형제로 만들 수 있으므로 그렇게 가정하면,

$$\text{Cost}(T''-\{x,y\}) = \text{Cost}(T'') - x.freq - y.freq < \text{Cost}(T) - x.freq - y.freq = \text{Cost}(T')$$

즉 $C'$에 대해 $T'$보다 비용이 낮은 트리 $T''-\{x,y\}$가 존재 — $T'$가 $C'$의 최적 트리라는 가정에 모순. 따라서 $T$는 $C$에 대해 최적이다.

Huffman 알고리즘은 이 과정을 반복해서 두 최소 빈도 노드를 계속 합쳐나가는 것이므로, Lemma 1·2를 귀납적으로 적용하면 알고리즘 전체의 최적성이 증명된다.

## 보강 — Prim's Algorithm의 Cut Property 형식적 증명

**용어 정의**
- **Cut**: 정점 집합 $V$를 두 부분으로 나누는 분할
- **간선 집합 $S$가 어떤 cut을 respect한다**: $S$에 속한 어떤 간선도 그 cut을 가로지르지 않음
- **Light edge**: 어떤 cut을 가로지르는 간선들 중 가중치가 가장 작은 간선

**Lemma (Cut Property)**: 간선 집합 $S$가 어떤 MST에 포함되어 있고, $S$를 respect하는 cut이 있다고 하자. 그 cut을 가로지르는 light edge $(u,v)$에 대해, $S \cup \{(u,v)\}$를 포함하는 MST가 존재한다.

**증명**: $S$를 포함하는 MST를 $T$라 하자.
- $(u,v) \in T$라면 이미 $T$가 $S \cup \{(u,v)\}$를 포함하는 MST이므로 끝.
- $(u,v) \notin T$라면, $T$에 $(u,v)$를 추가하면 사이클이 생긴다(스패닝 트리는 두 정점을 잇는 경로가 이미 유일하게 존재하므로). 이 사이클은 반드시 cut을 다시 가로지르는 다른 간선 $(x,y)$를 포함한다(사이클이 cut의 양쪽을 오가야 하므로 짝수 번 cut을 건너야 하고, $(u,v)$로 이미 한 번 건넜으니 최소 한 번 더 건너야 함).
- $T$에서 $(x,y)$를 빼고 $(u,v)$를 넣은 트리 $T'$을 생각하면, $T'$도 여전히 스패닝 트리(연결성 유지, 간선 수 동일)이고, $(u,v)$가 light edge이므로 $w(u,v) \le w(x,y)$, 따라서 $\text{cost}(T') \le \text{cost}(T)$.
- $T$가 이미 최소 비용이었으므로 $\text{cost}(T') = \text{cost}(T)$ — 즉 $T'$도 MST이며, $S$와 $(u,v)$를 모두 포함한다.

Prim's Algorithm은 매 단계 (트리에 포함된 정점 vs 그 외) cut에서 이 Lemma를 적용해 안전하게 간선을 하나씩 추가하는 것이므로, "지금까지 선택한 간선들을 포함하는 MST가 존재한다"는 불변식이 귀납적으로 유지되어 최종적으로 반환된 스패닝 트리가 MST임이 증명된다.
