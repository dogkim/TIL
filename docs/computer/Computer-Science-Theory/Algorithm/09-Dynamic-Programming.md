## DP란

부분문제들이 **겹치고(overlapping subproblems)**, **최적 부분구조(optimal substructure)**를 가질 때, 부분문제의 답을 저장해두고 재사용하는 방식.

- **Top-down (메모이제이션)**: 재귀 호출하면서 계산된 값을 저장 (예: 피보나치를 재귀로 구현하되 큰 값부터 호출)
- **Bottom-up (반복문)**: 작은 부분문제부터 순서대로 계산해 테이블을 채움 (Bellman-Ford, Floyd-Warshall, 반복적 피보나치)

## Bellman-Ford (단일 시작점 최단경로, 음수 가중치 허용)

Dijkstra와 달리 **음의 가중치 간선**을 허용 (단, 음수 사이클은 없다고 가정하거나, 음수 사이클 존재 자체를 검출).

**정의**: $d_i[v]$ = 시작점 $s$에서 $v$까지, **최대 $i$개의 간선**만 사용해서 갈 수 있는 최단경로 길이.

**초기화**: $d_0[s] = 0$, 나머지 $v$는 $d_0[v] = \infty$

**점화식**: $d_{i+1}[v] = \min\big(d_i[v],\; \min_{u}\{d_i[u] + w(u,v)\}\big)$ ($u$는 $v$로 들어오는 간선의 시작점)

**Correctness**: $s$에서 $v$까지 최대 $i+1$개의 간선을 쓰는 최단경로에서, $v$ 직전 정점을 $u$라 하면 그 경로는 $s$에서 $u$까지 최대 $i$개의 간선을 쓰는 최단경로 + 간선 $(u,v)$로 구성됨 (부분경로도 최단경로라는 성질).

**알고리즘**: $0 \sim n-2$까지 반복하며, 매 반복마다 모든 정점에 대해 위 점화식으로 갱신 (이웃 탐색 포함하면 반복당 $O(m)$)

**Time**: $n$번 반복 × 반복당 $O(m)$ = $O(nm)$

**음수 사이클 검출**: $n-1$번 반복 후에도 값이 계속 갱신되면(즉 $n$번째 반복에서도 값이 바뀌면) 음수 사이클이 존재.

## Floyd-Warshall (모든 쌍 최단경로, All-Pairs Shortest Path)

모든 정점 쌍 $(u,v)$의 최단경로를 한 번에 구함.

**정의**: $D^{(k)}[u,v]$ = 오직 $\{1,\dots,k\}$에 속한 정점만을 중간 경유지로 사용할 수 있을 때, $u$에서 $v$까지의 최단경로 길이.

**초기화**: $D^{(0)}[v,v]=0$, 간선 $(u,v)$가 있으면 $D^{(0)}[u,v]=w(u,v)$, 나머지는 $\infty$

**점화식**: $D^{(k)}[u,v] = \min\big(D^{(k-1)}[u,v],\; D^{(k-1)}[u,k] + D^{(k-1)}[k,v]\big)$

**증명 (귀납법, $k$에 대해)**
- $k=0$: 정의 그대로 자명
- $k-1$까지 성립한다고 가정. $k$ 단계에서:
  - $k$를 경유하지 않는 최단경로라면 $D^{(k)}[u,v] = D^{(k-1)}[u,v]$
  - $k$를 경유한다면, 음수 사이클이 없으므로 최단경로는 $k$를 딱 한 번만 지나는 단순경로 $u \rightsquigarrow k \rightsquigarrow v$. 이때 $u \rightsquigarrow k$와 $k \rightsquigarrow v$ 각각은 단순경로이므로 $k$를 다시 경유하지 않고 $\{1,\dots,k-1\}$만 경유함 → $D^{(k)}[u,v] = D^{(k-1)}[u,k] + D^{(k-1)}[k,v]$
  - 두 경우 모두 옳은 최단경로 값을 나타내므로 점화식이 성립
- $D^{(n)}$은 모든 정점 $\{1,\dots,n\}$을 경유 가능하게 허용한 값이므로 실제 최단경로(shortest simple path)와 일치

**Time**: $n \times n$ 배열을 $n$번 갱신, 매 갱신마다 배열 전체 순회 $O(n^2)$ → 전체 $O(n^3)$. 보통 그래프는 간선이 정점보다 많으므로($m > n$), $O(nm)$인 Bellman-Ford를 모든 시작점에 대해 반복하는 것보다 유리한 경우가 많음.

## LCS (Longest Common Subsequence)

두 문자열 $x[1..m]$, $y[1..n]$의 최장 공통 부분수열 길이.

**점화식**: $C[i,0] = C[0,j] = 0$. $x[i] = y[j]$이면 $C[i,j] = C[i-1,j-1]+1$, 아니면 $C[i,j] = \max(C[i,j-1], C[i-1,j])$

**알고리즘**: 전체 $(m+1)\times(n+1)$ 배열을 앞에서부터 이중 for문으로 채움

**Time**: 이중 for문이므로 $O(nm)$

**역추적(backtracking)해서 실제 LCS 문자열을 복원**할 때는 $O(n+m)$ (테이블을 채운 뒤, $C[m,n]$에서 시작해 대각선/위/왼쪽 중 하나로만 이동하며 역추적하므로).

**공간**: 실제 LCS 문자열까지 복원해야 하면 전체 테이블 $O(nm)$이 필요하지만, **길이만** 필요하면 이전 행만 유지하면 되므로 $O(n)$으로 절약 가능.

## 0/1 Knapsack

무게 제한 $x$인 배낭에, 각각 무게 $W_i$와 가치 $V_i$를 가진 $n$개의 물건 중 일부를 담아 가치 합을 최대화.

**정의**: $K[x,i]$ = 무게 제한 $x$, 처음 $i$개의 물건만 고려했을 때 얻을 수 있는 최대 가치

**초기화**: $K[x,0] = 0$ (물건이 없으면 가치 0), $K[0,i] = 0$ (무게 제한 0이면 아무것도 못 담음)

**점화식** ($x$, $i$를 순회하며 채움)
- 기본값으로 이전 값을 그대로 가져옴: $K[x,i] = K[x,i-1]$ ($i$번째 물건을 안 담는 경우)
- $x \ge W_i$이면(담을 수 있으면): $K[x,i] = \max\big(K[x,i-1],\; K[x-W_i,\,i-1] + V_i\big)$

**Time**: $O(nx)$ (테이블 크기가 $x \times n$이고 각 칸이 $O(1)$)
