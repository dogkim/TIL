## Red-Black Trees

균형이 자동으로 유지되는 이진 탐색 트리. 각 노드는 red 또는 black 색을 가지며, 다음 성질을 만족:

1. 모든 노드는 red 또는 black
2. 루트는 black
3. 모든 리프(NIL)는 black
4. red 노드의 자식은 항상 black (red가 연속으로 나올 수 없음)
5. 임의의 노드에서 그 자손인 리프까지의 모든 경로는 같은 수의 black 노드를 지남 (**black-height**, $bh(x)$)

이 성질들 덕분에 가장 긴 경로가 가장 짧은 경로의 2배를 넘지 않아, 높이가 $O(\log n)$으로 유지됨.

**귀납 증명 — $x$를 루트로 하는 서브트리는 최소 $2^{bh(x)} - 1$개의 내부(NIL이 아닌) 노드를 가짐**
- 기저: $x$가 리프(NIL)면 $bh(x) = 0$, 내부 노드 수 $0 = 2^0 - 1$
- 귀납: $x$의 각 자식의 black-height는 $bh(x)$ 또는 $bh(x)-1$ (자식이 red면 $bh(x)$, black이면 $bh(x)-1$)
  - 각 자식 서브트리는 최소 $2^{bh(x)-1}-1$개의 내부 노드를 가짐 (귀납 가정)
  - $x$ 서브트리 전체: $2(2^{bh(x)-1}-1) + 1 = 2^{bh(x)} - 1$

이로부터 $n$개의 내부 노드를 가진 red-black tree의 높이는 $O(\log n)$임을 유도할 수 있음 (red가 연속될 수 없으므로 $bh(x) \ge h(x)/2$).

## Hashing

**해시 함수 $h$**: 키의 전체 공간(universe)을 더 작은 크기의 해시 테이블 슬롯으로 대응시키는 함수.

**Direct addressing**과의 차이: universe가 커서 직접 주소 지정이 비현실적일 때, 해시 함수로 압축된 주소공간을 사용. 직접 주소 지정에 필요한 비트 수가 $M$이라면, 해시 테이블은 훨씬 작은 공간만 사용.

**충돌(collision)**: 서로 다른 두 키가 같은 슬롯에 매핑되는 것 — 해시 테이블 크기가 유한한 이상 피할 수 없음(비둘기집 원리).

**균등 해싱 가정(Simple Uniform Hashing)**: 각 키는 $m$개의 슬롯 중 하나에 독립적이고 균등하게 매핑된다고 가정.
- 어떤 슬롯 $j$에 들어가는 키 개수의 기댓값: $E[\text{슬롯 } j\text{의 항목 수}] = \sum_{k} P\{h(x_k) = j\} = n/m$ (적재율 $\alpha = n/m$)

**Hash Family (해시 함수족)**: 미리 정해진 하나의 해시 함수만 쓰면 적대적인 입력에 의해 항상 최악의 충돌이 발생할 수 있음. 이를 막기 위해, 해시 함수들의 집합(family)에서 **무작위로 하나를 선택**해 사용.
- **Universal Hash Family**: 서로 다른 두 키 $x \ne y$를 뽑았을 때, family에서 무작위로 선택한 해시 함수 $h$에 의해 두 키가 같은 슬롯에 담길 확률이 $1/m$ 이하인 family
- 이 성질 덕분에, 어떤 특정 입력에 대해서도 평균적으로 충돌이 적게 유지됨을 보장할 수 있음 (적대적 입력에 대한 방어)
