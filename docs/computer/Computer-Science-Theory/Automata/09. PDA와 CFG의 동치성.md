앞서 `08. 푸시다운 오토마타(PDA)`에서 살펴본 것처럼, 어떤 언어가 CFG로 생성될 수 있는 것과 PDA(empty stack 혹은 final state, 둘은 서로 동치)로 인식될 수 있는 것은 같은 이야기다.

$$\text{Grammar} \iff \text{PDA by empty stack} \iff \text{PDA by final state}$$

여기서는 두 방향의 구체적인 변환 방법과 증명을 다룬다.

## CFG에서 PDA로

CFG $G$의 leftmost derivation $S\Rightarrow^*_{lm} w$를 그대로 시뮬레이션하는 **단 하나의 state만 가지는** PDA를 만들 수 있다는 것이 핵심 아이디어이다.

left-sentential form을 $x\underbrace{A\alpha}_{}$ 라고 쓰자. 여기서 $A$는 가장 왼쪽 변수, $x$는 그 왼쪽에 이미 확정된 터미널들, $\alpha$는 $A$ 오른쪽에 남은 (터미널+변수) 문자열이다.

$xA\alpha \Rightarrow_{lm} x\beta\alpha$라는 한 단계는, PDA가 이미 $x$까지 입력을 소비하고 스택에 $A\alpha$를 올려둔 상태에서, $\epsilon$-전이로 $A$를 pop하고 $\beta$를 push하는 것에 대응된다. 이후 $\beta$의 앞부분에 터미널이 있으면, 입력의 대응 부분과 맞춰가며 그 터미널들을 pop한다. 모든 추측이 맞았다면 결국 스택도 입력도 동시에 바닥나게 된다.

**구성**. $G=(V,T,S,P)$가 주어지면, $L(G)$를 empty stack으로 인정하는 (1-state) PDA $M_N$을

$$M_N = (\{q\},\ T,\ V\cup T,\ \delta,\ q,\ S)$$

$\delta$는 다음과 같이 정의:

1. 각 변수 $A$에 대해: $\delta(q,\epsilon,A) = \{(q,\beta)\mid A\to\beta\in P\}$
2. 각 터미널 $a$에 대해: $\delta(q,a,a) = \{(q,\epsilon)\}$

**정리**. $L(M_N) = L(G)$.

**증명(If: $w\in L(G)\Rightarrow w\in L(M_N)$)**. $S=\gamma_1\Rightarrow_{lm}\gamma_2\Rightarrow_{lm}\cdots\Rightarrow_{lm}\gamma_n=w$라 하고, $\gamma_i=x_i\alpha_i$ ($\alpha_i$는 tail)라 하자. $S\Rightarrow^*_{lm}\gamma_i$이면 $(q,w,S)\vdash^*(q,y_i,\alpha_i)$ (단, $w=x_iy_i$)임을 $i$에 대한 귀납법으로 보인다.

- **기저**: $i=1$이면 $\gamma_1=S$, $x_1=\epsilon,\ y_1=w$. 자명하게 $(q,w,S)\vdash^*(q,w,S)$.
- **귀납**: $\alpha_i$가 변수 $A$로 시작한다고 하면 $\gamma_i=x_iA\xi \Rightarrow_{lm} x_i\beta\xi=\gamma_{i+1}$. 귀납 가정에 의해 스택에 $A\xi$가, 미소비 입력이 $y_i$인 상태이므로, $M_N$의 구성에 의해 $(q,y_i,A\xi)\vdash^*(q,y_i,\beta\xi)$로 이동 가능. $\beta$의 앞부분에 터미널이 있으면 그만큼 매칭되는 입력과 함께 pop하여 $(q,y_{i+1},\alpha_{i+1})$에 도달.

$\gamma_n=w$이므로 $\alpha_n=\epsilon,\ y_n=\epsilon$, 따라서 $(q,w,S)\vdash^*(q,\epsilon,\epsilon)$, 즉 $w\in L(M_N)$.

**증명(Only-if: $w\in L(M_N)\Rightarrow w\in L(G)$)**. $\vdash^*$의 길이에 대한 귀납법으로 다음을 보인다.

$$\text{if } (q,x,A)\vdash^*(q,\epsilon,\epsilon) \text{ then } A\Rightarrow^* x \tag{1}$$

- **기저**(길이 1): $A\to\epsilon\in P$이고 $(q,\epsilon)\in\delta(q,\epsilon,A)$이므로 $A\Rightarrow\epsilon$.
- **귀납**: $A\to Y_1Y_2\cdots Y_k\in P$를 사용해 $(q,x,A)\vdash(q,x,Y_1\cdots Y_k)\vdash^*\cdots\vdash^*(q,\epsilon,\epsilon)$이라 하면, $x$를 $x_1x_2\cdots x_k$로 쪼갤 수 있다 ($x_i$는 $Y_i$가 pop되는 동안 소비된 입력). 각 $Y_i$가 변수이면 귀납 가정에 의해 $Y_i\Rightarrow^*x_i$, 터미널이면 $Y_i=x_i$ (길이 1). 따라서 $A\Rightarrow Y_1\cdots Y_k \Rightarrow^* x_1Y_2\cdots Y_k\Rightarrow^*\cdots\Rightarrow^* x_1x_2\cdots x_k=x$.

$A=S,\ x=w$로 두면 $(1)$에서 $S\Rightarrow^*w$, 즉 $w\in L(G)$. $\blacksquare$

> **다른 버전(sentential form 유지 방식)**: $(q,xw,S)\vdash^*(q,w,\alpha) \Rightarrow S\Rightarrow^*_{lm}x\alpha$ 라는 좀 더 일반적인 statement를 세우고, $\vdash$ 한 스텝이 "터미널 매칭"인지 "변수 전개"인지 두 경우로 나눠 귀납하면 같은 결론에 도달한다. ($x=\epsilon,\alpha=\epsilon$일 때가 원래 명제)

## PDA에서 CFG로

PDA $M_N$이 입력 $x=x_1x_2\cdots x_k$를 소비하며 스택을 완전히 비우는 과정을, 변수 $[p_{i-1}Y_ip_i]$ — "state $p_{i-1}$에서 $p_i$로 가면서 스택 심볼 $Y_i$ 하나를 순수하게 pop해서 없애는 효과" — 로 표현하는 문법을 만든다.

**구성**. $M_N=(Q,\Sigma,\Gamma,\delta,q_0,Z_0)$가 주어지면, $G=(V,\Sigma,S,P)$를

$$V = \{[pXq]\mid p,q\in Q,\ X\in\Gamma\}\cup\{S\}$$

$$P = \{S\to[q_0Z_0p]\mid p\in Q\}\ \cup\ \{[qXr_k]\to a[rY_1r_1][r_1Y_2r_2]\cdots[r_{k-1}Y_kr_k]\ \mid\ a\in\Sigma\cup\{\epsilon\},\ \{r_1,\dots,r_k\}\subseteq Q,\ (r,Y_1Y_2\cdots Y_k)\in\delta(q,a,X)\}$$

state 개수가 $n$일 때, $S$에 대한 규칙은 $n$개, 각 전이당 생성되는 규칙은 최대 $n^2$개(첫 번째 목적지 $r$과 마지막 목적지 $r_k$의 조합 수)이다.

#### 작은 예시
$M_N=(\{q\},\{i,e\},\{Z\},\delta_N,q,Z)$, $\delta_N(q,i,Z)=\{(q,ZZ)\}$, $\delta_N(q,e,Z)=\{(q,\epsilon)\}$ (if-else 문 개수 맞추기)를 변환하면, $[qZq]$ 하나만 유의미한 변수로 남고

$$S\to[qZq],\qquad [qZq]\to i[qZq][qZq]\mid e.$$

$[qZq]$를 $A$로 다시 쓰면 익숙한 $S\to A,\ A\to iAA\mid e$를 얻는다.

### 정리와 증명

**정리**. 위와 같이 구성한 $G$에 대해 $L(G)=L(M_N)$.

**증명(If)**. 다음을 $\vdash^*$의 길이에 대한 귀납법으로 보인다.

$$\text{if } (q,w,X)\vdash^*(p,\epsilon,\epsilon)\ \text{then}\ [qXp]\Rightarrow^*w \tag{2}$$

- **기저**(길이 1): $w$는 $a$나 $\epsilon$ 하나이고 $(p,\epsilon)\in\delta(q,w,X)$. 구성에 의해 $[qXp]\to w\in P$이므로 $[qXp]\Rightarrow^*w$.
- **귀납**: $(q,w,X)\vdash(r_0,x,Y_1Y_2\cdots Y_k)\vdash^*\cdots\vdash^*(p,\epsilon,\epsilon)$ (단, $w=ax$ 혹은 $w=\epsilon x$)라 하면, $(r_0,Y_1\cdots Y_k)\in\delta(q,a,X)$이므로 구성에 의해 규칙 $[qXr_k]\to a[r_0Y_1r_1]\cdots[r_{k-1}Y_kr_k]$가 존재한다 (여기서 $r_i$는 $Y_i$가 pop되는 순간의 state로 고를 수 있음). $w=aw_1w_2\cdots w_k$ ($w_i$는 $Y_i$를 pop하며 소비된 입력)로 쪼개면, 귀납 가정에 의해 각 $[r_{i-1}Y_ir_i]\Rightarrow^*w_i$이므로

$$[qXr_k] \Rightarrow a[r_0Y_1r_1]\cdots[r_{k-1}Y_kr_k] \Rightarrow^* aw_1[r_1Y_2r_2]\cdots \Rightarrow^*\cdots\Rightarrow^* aw_1w_2\cdots w_k = w.$$

$A=S$에서 시작해 $(q_0,w,Z_0)\vdash^*(p,\epsilon,\epsilon)$이면 $S\to[q_0Z_0p]$와 $(2)$에 의해 $S\Rightarrow^*w$, 즉 $L(M_N)\subseteq L(G)$.

**증명(Only-if)**. 대칭적으로, $\Rightarrow^*$의 길이에 대한 귀납법으로

$$\text{if } [qXp]\Rightarrow^*w \ \text{then}\ (q,w,X)\vdash^*(p,\epsilon,\epsilon) \tag{3}$$

을 보이면(기저와 귀납 단계는 $(2)$의 증명을 그대로 뒤집은 구조), $S\Rightarrow^*w$이면 어떤 $[q_0Z_0p]\Rightarrow^*w$가 존재하므로 $(q_0,w,Z_0)\vdash^*(p,\epsilon,\epsilon)$, 즉 $w\in L(M_N)$. 따라서 $L(G)\subseteq L(M_N)$이고, 두 방향을 합쳐 $L(G)=L(M_N)$. $\blacksquare$

## 정리: 세 표현의 동치성

$$\text{CFG} \iff \text{NPDA (empty stack)} \iff \text{NPDA (final state)}$$

이 세 가지는 모두 같은 언어 class(문맥 자유 언어, CFL)를 정의하는 동치인 방법이다. (final state $\leftrightarrow$ empty stack 상호 변환은 `08. 푸시다운 오토마타(PDA)` 참고)
