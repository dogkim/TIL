`11. 튜링 기계`에서 정의한 표준 TM에 여러 기능을 추가한 변형 모델들을 살펴본다. 결론부터 말하면, 이 변형들은 모두 **표준 TM과 동일한 계산 능력**을 가진다 — 더 편리해 보일 뿐, 새로운 언어를 인식할 수 있게 해주지는 않는다.

## 동치성과 시뮬레이션

**정의**. 두 오토마타가 같은 언어를 인식하면 **동치(equivalent)**이다.

**정의**. 두 오토마타 class $C_1,C_2$에 대해, $C_1$의 모든 오토마타 $M_1$에 대응하는 $M_2\in C_2$가 존재해 $L(M_1)=L(M_2)$이면 "$C_2$는 $C_1$만큼 강력하다"고 한다. 역방향도 성립하면 $C_1,C_2$는 동치이다.

이러한 동치성을 보이는 대표적인 기법이 **시뮬레이션(simulation)**이다. $M$의 계산 과정(ID 수열) $d_0\vdash_M d_1\vdash_M\cdots\vdash_M d_n$에 대해, 다른 오토마타 $\hat M$이

$$\hat d_0 \vdash^*_{\hat M} \hat d_1 \vdash^*_{\hat M} \cdots \vdash^*_{\hat M} \hat d_n$$

처럼, $M$의 각 configuration $d_i$에 **일대일로 대응**되는 자신만의 configuration $\hat d_i$를 거쳐가는 계산을 수행할 수 있으면 "$\hat M$이 $M$을 시뮬레이션한다"고 한다. ($\hat M$은 $M$의 한 스텝을 여러 스텝에 걸쳐 흉내 낼 수 있다 — 그래서 $\vdash$가 아니라 $\vdash^*$)

## TM with Stay-Option

$$\delta: Q\times\Gamma \to Q\times\Gamma\times\{L,R,S\}$$

헤드가 그 자리에 머무는($S$, stay) 선택지를 추가한 모델.

**정리**. Stay-option이 있는 TM은 표준 TM과 동치이다.

**증명 스케치**. 표준 TM은 당연히 stay-option TM의 특수한 경우이므로 시뮬레이션 가능. 역방향: stay-option TM $M$의 한 스텝이 $L$이나 $R$이면 표준 TM $\hat M$이 그대로 한 스텝으로 흉내 낸다. $S$가 쓰였다면, $\hat M$은 오른쪽으로 한 칸 갔다가 다시 왼쪽으로 한 칸 오는 **두 스텝**으로 같은 효과(제자리 유지)를 낸다.

## TM with Multiple Tracks (다중 트랙)

하나의 테이프를 여러 개의 "트랙(track)"으로 나눠, 한 칸에 여러 심볼(트랙 개수만큼)을 동시에 기록하는 모델. 예를 들어 3-트랙이면 테이프 알파벳이 $\Gamma^3$처럼 취급된다.

### 활용 예시: $01^*+10^*$를 인식하는 TM

"처음 본 심볼이 0인지 1인지"를 기억해 두었다가, 이후 나머지 위치에서 그 심볼이 다시 나오지 않는지 확인해야 하는데, 이는 **finite control 안에 정보를 추가로 담는 것**(state를 $\{q_0,q_1\}\times\{0,1,\sqcup\}$처럼 확장)으로도 구현할 수 있다.

$$M = (Q,\ \{0,1\},\ \{0,1,\sqcup\},\ \delta,\ [q_0,\sqcup],\ \sqcup,\ \{[q_1,\sqcup]\}), \qquad Q=\{q_0,q_1\}\times\{0,1,\sqcup\}$$

$$\delta([q_0,\sqcup],a) = ([q_1,a],\,a,\,R) \quad (a=0\text{ 또는 }1)$$
$$\delta([q_1,a],\bar a) = ([q_1,a],\,\bar a,\,R) \quad (\bar a\text{는 }a\text{의 반대 심볼})$$
$$\delta([q_1,a],\sqcup) = ([q_1,\sqcup],\,\sqcup,\,R)$$

즉, "처음 본 심볼을 state 안에 저장해 두고 계속 이동한다"는 아이디어는 **다중 트랙 없이도 state 수를 늘리는 것만으로** 구현 가능함을 보여준다 — 다중 트랙 역시 결국 표준 TM으로 환원 가능한 편의 기능일 뿐이다.

## Multitape TM (다중 테이프)

$$\delta: Q\times\Gamma^n \to Q\times\Gamma^n\times\{L,R\}^n$$

테이프가 $n$개이고, 각 테이프마다 독립적인 헤드가 있어 한 스텝에 모든 헤드를 (각자 다른 방향으로) 동시에 움직일 수 있는 모델.

**정리**. 다중 테이프 TM이 인식하는 모든 언어는 recursively enumerable하다 (= 표준 단일 테이프 TM으로도 인식 가능하다).

**시뮬레이션 아이디어**(개요): 단일 테이프 TM은 $n$개의 트랙을 사용해 $n$개의 테이프 내용을 한 테이프에 나란히 표현하고, 각 트랙마다 "현재 헤드 위치"를 표시하는 marker를 추가 트랙으로 둔다. 한 스텝을 시뮬레이션하려면, 단일 테이프 TM은 전체 테이프를 좌우로 훑으며 각 헤드 위치의 심볼들을 모두 읽어들인 뒤(여러 스텝), 원래 TM의 전이 규칙에 따라 각 marker와 심볼을 갱신한다 — 한 스텝이 여러 스텝으로 늘어날 뿐, 계산 가능성 자체는 바뀌지 않는다.

## TM with Semi-Infinite Tape (한쪽만 무한한 테이프)

테이프가 왼쪽 끝은 막혀 있고 오른쪽으로만 무한히 늘어나는 모델. 왼쪽 경계를 넘어가려는 이동은 허용하지 않는다 (혹은 그 자리에 머무르게 한다).

**아이디어**: 양방향 무한 테이프의 내용을 "왼쪽 절반"과 "오른쪽 절반"으로 나누어, 한쪽 끝이 막힌 테이프 위에 **두 트랙**으로 접어(fold) 표현할 수 있다. 원래 테이프의 시작 지점을 기준으로 왼쪽으로 가는 이동은 한쪽 트랙에서, 오른쪽으로 가는 이동은 다른쪽 트랙에서 각각 진행하는 것으로 시뮬레이션한다. 따라서 한쪽만 무한한 테이프를 가진 TM도 표준 TM과 동치이다.

## Nondeterministic TM (NTM)

$$\delta: Q\times\Gamma \to 2^{Q\times\Gamma\times\{L,R\}}$$

한 configuration에서 여러 개의 다음 이동이 가능한 모델 (NFA가 DFA를 일반화하듯).

**정리**. 결정적 TM(DTM)의 class와 비결정적 TM(NTM)의 class는 동치이다.

**시뮬레이션 아이디어**(개요): NTM의 계산은 매 스텝마다 갈라지는 **트리** 구조를 이룬다. DTM은 이 트리를 너비 우선 탐색(BFS) 방식으로 시뮬레이션한다 — 다중 테이프(혹은 트랙)를 이용해 "지금까지의 각 분기 경로"를 순서대로 하나씩 재현해보고, 그중 하나라도 accept에 도달하면 그 순간 accept한다. (깊이 우선으로 하면 무한 루프에 빠지는 분기 하나 때문에 다른 분기를 영영 확인 못 할 수 있어, 반드시 너비 우선으로 접근해야 한다.)

> NFA↔DFA의 동치성과 달리, 이 경우 state 수의 폭발적 증가(subset construction)가 일어나는 것이 아니라 **시간(스텝 수)이 지수적으로 증가**하는 방식으로 시뮬레이션이 이루어진다는 점이 중요한 차이다 — 이는 뒤에 이어지는 계산 복잡도(P vs NP) 논의의 핵심 배경이 된다.

## Linear Bounded Automata (LBA)

이번 강의의 outline에는 있었지만, 다중 테이프·비결정적 TM과 달리 LBA는 테이프 길이가 **입력 길이에 비례해 제한**된다는 점에서 표준 TM보다 약한(context-sensitive language를 인식하는) 모델이다. (본 자료에는 LBA의 formal한 정의나 증명까지는 다뤄지지 않았다.)

## 정리

| 모델 | 표준 TM과의 관계 |
|---|---|
| Stay-option TM | 동치 |
| 다중 트랙 TM | 동치 (state 확장으로 환원) |
| 다중 테이프 TM | 동치 (트랙+marker로 환원) |
| 한쪽만 무한한 테이프 TM | 동치 (두 트랙으로 접어서 환원) |
| 비결정적 TM | 동치 (BFS 시뮬레이션, 단 시간은 지수적으로 증가) |

이처럼 다양한 방식으로 기능을 추가해도 "인식 가능한 언어의 class" 자체는 표준 TM에서 한 치도 벗어나지 않는다 — 이것이 바로 TM이 계산 가능성의 보편적인 기준점으로 받아들여지는 이유다.
