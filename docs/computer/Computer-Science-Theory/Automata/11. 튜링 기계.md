## 왜 튜링 기계인가

DFA는 메모리가 없고, PDA는 스택(LIFO) 하나만큼의 메모리를 가진다. **튜링 기계(Turing Machine, TM)**는 양방향으로 무한히 늘어나는 **테이프(tape)**를 자유롭게 읽고 쓸 수 있는, 가장 강력한 계산 모델이다. Alan Turing이 1930년대에 제안했으며, 오늘날 "계산 가능하다(computable)"는 개념 자체가 이 모델을 기준으로 정의된다.

## 튜링 기계의 정의

**정의**. 튜링 기계 $M$은 7-tuple $M=(Q,\Sigma,\Gamma,\delta,q_0,\sqcup,F)$로 정의된다.

- $Q$: 내부 state들의 유한 집합
- $\Sigma$: 입력 알파벳 ($\Sigma\subseteq\Gamma-\{\sqcup\}$)
- $\Gamma$: 테이프 알파벳 (입력 심볼 + 특수 심볼들, 빈칸 포함)
- $\delta: Q\times\Gamma \to Q\times\Gamma\times\{L,R\}$: 전이 함수
- $q_0\in Q$: 시작 state
- $\sqcup$: 빈칸(blank) 심볼
- $F\subseteq Q$: 종료 state 집합

DFA/PDA와 가장 다른 점: 전이 함수의 두 번째 인자가 "입력 심볼"이 아니라 **테이프 위 현재 위치의 심볼**이고, 결과로 (다음 state, 그 위치에 쓸 심볼, 헤드 이동 방향 $L/R$)을 준다는 것이다. 즉 TM은 테이프를 **읽고(read) 쓰고(write) 이동(move)**할 수 있다.

### 예시
$Q=\{q_0,q_1\}$, $\Sigma=\{a,b\}$, $\Gamma=\{a,b,\sqcup\}$, $F=\{q_1\}$이고

$$\delta(q_0,a)=(q_0,b,R),\quad \delta(q_0,b)=(q_0,b,R),\quad \delta(q_0,\sqcup)=(q_1,\sqcup,L)$$

이 TM에 $w=aabb$를 주면: 모든 $a$를 $b$로 바꾸며 오른쪽 끝(빈칸)까지 이동한 뒤, 한 칸 왼쪽으로 이동하고 $q_1$(종료 state)에서 멈춘다.

### Halt(정지)

- TM은 $\delta$가 정의되지 않은 configuration에 도달하면 **halt**한다.
- 종료 state에서는 전이가 정의되어 있지 않다고 가정하므로, 종료 state에 들어가면 자동으로 halt한다.
- 하지만 TM이 항상 halt한다는 것을 (accept든 reject든) 보장할 수는 없다 — 무한 루프에 빠질 수 있다.
- **항상 halt하는 TM**은 알고리즘의 좋은 모델이다. 어떤 문제를 해결하는 알고리즘(항상 halt하는 TM)이 존재하면, 그 문제는 **decidable(결정 가능)**하다고 한다.

### 표준 튜링 기계의 특징

1. 테이프는 양방향으로 무한하며, 좌우로 몇 번이든 이동 가능
2. 결정적(deterministic): $\delta$는 각 configuration에서 최대 하나의 이동만 정의
3. 별도의 입력 파일이나 출력 장치 없이, 오직 테이프 하나로만 입출력을 처리

## Instantaneous Description (ID)

$$x_1\,q\,x_2 = a_1\cdots a_{k-1}\,q\,a_k\cdots a_n$$

현재 헤드가 가리키는 위치 바로 앞에 state $q$를 적어, "왼쪽에 $x_1$, 지금 state $q$에서 헤드가 가리키는 위치부터 오른쪽에 $x_2$"를 나타낸다.

앞의 예시(TM이 $a$를 $b$로 바꾸는 예)의 ID 수열은

$$q_0aabb \vdash bq_0abb \vdash bbq_0bb \vdash bbbq_0b \vdash bbbbq_0\sqcup \vdash bbbq_1b$$

## TM이 인식하는 언어

**계산(computation)**: halt state에 도달하는 configuration들의 수열.

**정의**. $M=(Q,\Sigma,\Gamma,\delta,q_0,\sqcup,F)$에 대해

$$L(M) = \{w\in\Sigma^+ \mid q_0w \vdash^* x_1q_fx_2,\ q_f\in F,\ x_1x_2\in\Gamma^*\}$$

$w\notin L(M)$일 때는 두 가지 경우가 있다: (1) 종료 state가 아닌 곳에서 halt하거나, (2) 무한 루프에 빠져 영영 halt하지 않는다($x_1qx_2\vdash^*\infty$).

### 예제 1: $\Sigma=\{0,1\}$에서 $00^*$를 인식하는 TM

각 심볼을 읽으며 0인지 확인하고 오른쪽으로 이동한다. 빈칸에 도달할 때까지 계속 0만 봤다면 accept, 중간에 1이 있으면 그 자리에서 halt(비종료 state)한다.

$$\delta(q_0,0)=(q_0,0,R),\qquad \delta(q_0,\sqcup)=(q_f,\sqcup,R).$$

### 예제 2: $L=\{a^nb^n\mid n\ge1\}$를 인식하는 TM

**아이디어**: 가장 왼쪽 $a$를 $x$로 지우고(체크 표시), 오른쪽으로 이동해 가장 왼쪽 $b$를 찾아 $y$로 지운다. 다시 왼쪽으로 이동해 다음 $a$를 찾아 $x$로, 다음 $b$를 찾아 $y$로 표시하며 왕복한다. 결국 $a,b$가 하나도 남지 않으면 $L$에 속한다.

$\Gamma=\{a,b,x,y,\sqcup\}$, $F=\{q_4\}$, $Q=\{q_0,q_1,q_2,q_3,q_4\}$

- **오른쪽으로 이동, $a\to x$, 짝지을 $b$ 찾기**:
    $$\delta(q_0,a)=(q_1,x,R),\quad \delta(q_1,a)=(q_1,a,R),\quad \delta(q_1,y)=(q_1,y,R),\quad \delta(q_1,b)=(q_2,y,L)$$
- **왼쪽으로 이동해 $x$까지 되돌아가기**:
    $$\delta(q_2,y)=(q_2,y,L),\quad \delta(q_2,a)=(q_2,a,L),\quad \delta(q_2,x)=(q_0,x,R)$$
- **종료 확인** (모든 $a,b$가 $x,y$로 치환되었는지):
    $$\delta(q_0,y)=(q_3,y,R),\quad \delta(q_3,y)=(q_3,y,R),\quad \delta(q_3,\sqcup)=(q_4,\sqcup,R)$$

$w=aabb$에 대한 ID 수열:

$$q_0aabb\vdash xq_1abb\vdash xaq_1bb\vdash xq_2ayb \vdash q_2xayb\vdash xq_0ayb\vdash xxq_1yb\vdash xxyq_1b\vdash xxq_2yy\vdash xq_2xyy\vdash xxq_0yy\vdash xxyq_3y\vdash xxyyq_3\sqcup\vdash xxyy\sqcup q_4\sqcup$$

> 참고: $L=\{a^nb^nc^n\mid n\ge1\}$는 CFL이 아니지만(→ `10. 문맥 자유 언어의 성질`의 펌핑 렘마), 비슷한 방식(문자들을 하나씩 체크 표시하며 왕복)으로 TM으로는 인식 가능하다. 이것이 바로 TM이 PDA보다 강력하다는 것을 보여주는 예다.

## TM을 함수 계산기로 보기 (Transducer)

TM $M$을 함수 $f$의 구현체로 볼 수도 있다:

$$\hat w = f(w) \quad\text{단}\quad q_0w \vdash^*_M q_f\hat w,\ q_f\in F$$

**정의**. 정의역 $D$를 가지는 함수 $f$가 **Turing-computable**(또는 그냥 computable)하다는 것은, 어떤 TM $M$이 존재해 모든 $w\in D$에 대해

$$q_0w \vdash^*_M q_f f(w),\qquad q_f\in F$$

가 성립하는 것이다. (일반적으로 알려진 거의 모든 수학 함수는 아무리 복잡해도 Turing-computable하다 — 이는 계산 가능성 이론의 근본 명제인 **Church–Turing 명제**와 연결된다.)

### 예제

- **덧셈**: 양의 정수 $x,y$가 unary(단항, 1의 개수로 표현)로 주어질 때 $x+y$를 계산. $w(x)\,1\,w(y)$ (구분자 1로 붙인 두 unary 수) 사이의 구분자 1을 오른쪽 끝으로 옮기면, 두 문자열이 그냥 이어붙여지는 것만으로 덧셈이 완성된다.
- **문자열 복사**: $\forall w\in 0^+$에 대해 $q_0w\vdash^*q_fww$가 되도록 하는 TM. (1) 모든 0을 $X$로 치환 (2) 가장 오른쪽 $X$를 찾아 0으로 되돌림 (3) 현재 비어있지 않은 영역의 오른쪽 끝으로 가서 0을 하나 새로 씀 (4) $X$가 모두 없어질 때까지 (2)-(3) 반복.
- **음이 아닌 뺄셈**: $x\ominus y=\max(x-y,0)$을 unary로 계산. (양쪽에서 하나씩 지워나가는 방식으로 구현)

이처럼 TM은 accept/reject를 판정하는 "인식기"로도, 입력을 출력으로 바꾸는 "계산기"로도 쓰일 수 있다 — 사실 원래 튜링이 제안한 모델의 관점은 후자(정수 함수의 계산기)에 가까웠다.
