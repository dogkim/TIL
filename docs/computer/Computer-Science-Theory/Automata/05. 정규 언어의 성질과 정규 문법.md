## 정규 표현식과 유한 오토마타의 동치성

DFA/NFA(machine-like description)와 정규 표현식(algebraic description)은 서로 표현력이 동일하다. 즉, 어떤 언어가 정규 표현식으로 표현 가능 $\iff$ 어떤 NFA(또는 DFA)로 인식 가능하다.

### 1. 정규 표현식 $\to$ NFA

임의의 정규 표현식 $r$에 대해 $L(r)$을 인식하는 NFA를 귀납적으로 구성할 수 있다.

- **기본 요소**: $\emptyset,\ \epsilon,\ a \in \Sigma$ 각각에 대해 시작 state 하나, 종료 state 하나로 이루어진 간단한 NFA를 만든다. ($\emptyset$은 전이가 없는 NFA, $\epsilon$은 $\epsilon$-전이 하나로 연결된 NFA, $a$는 $a$-전이 하나로 연결된 NFA)
- **재귀 단계**: $r_1, r_2$에 대한 NFA $M(r_1), M(r_2)$가 이미 구성되어 있다고 하자 (일반성을 잃지 않고 각각 종료 state가 하나뿐이라고 가정 가능).
    - $L(r_1+r_2)$: 새로운 시작 state에서 $M(r_1),M(r_2)$의 시작 state로 각각 $\epsilon$-전이, 두 NFA의 종료 state에서 새로운 종료 state로 각각 $\epsilon$-전이
    - $L(r_1 r_2)$: $M(r_1)$의 종료 state에서 $M(r_2)$의 시작 state로 $\epsilon$-전이 (직렬 연결)
    - $L(r_1^*)$: $M(r_1)$을 감싸서 시작과 끝에 새로운 state를 추가하고, 시작→끝으로 바로 가는 $\epsilon$-전이(0번 반복)와 끝→시작으로 되돌아가는 $\epsilon$-전이(반복)를 추가

이 구성을 반복 적용하면 임의의 정규 표현식에 대한 NFA를 얻을 수 있으므로, **$L(r)$은 항상 regular language**이다.

### 2. 유한 오토마타 $\to$ 정규 표현식 (일반화된 전이 그래프)

**Generalized Transition Graph (GTG)**: edge의 label이 (단일 심볼이 아니라) 정규 표현식인 transition graph.

임의의 NFA $M$은 하나의 GTG로 볼 수 있다 (단, 시작 state는 하나, 종료 state도 하나이고 시작 state로 들어오는 edge와 종료 state에서 나가는 edge가 없다고 일반화해도 무방 — 필요하면 새로운 시작/종료 state를 $\epsilon$-전이로 추가).

**State 제거법(state elimination)**: GTG에서 state $q$ (시작/종료가 아닌)를 제거할 때, $q$를 거쳐 가는 모든 경로를 $q$를 거치지 않는 하나의 edge로 대체한다.

$q_i \xrightarrow{a} q \xrightarrow{e^*} q_j$ 와 같은 경로가 있으면(자기 자신으로 돌아오는 loop $e$ 포함), $q$를 지우고 $q_i \xrightarrow{ae^*} q_j$ 라는 새 edge로 합친다. 즉, $q$에 인접한 모든 in-edge $a$, self-loop $e$, out-edge $d$에 대해

$$q_i \xrightarrow{ae^*d} q_j$$

라는 edge를 새로 만든다(기존에 $q_i \to q_j$ edge $b$가 있었다면 union으로 합쳐 $ae^*d + b$).

이 과정을 시작/종료 state 둘만 남을 때까지 반복하면, 다음과 같은 **canonical form**(두 state $q_i, q_j$ 사이에 4개의 edge $r_1$(자기 loop, $q_i$), $r_2$($q_i\to q_j$), $r_3$($q_j\to q_i$), $r_4$(자기 loop, $q_j$))만 남는다. 이때 전체 언어에 대응하는 정규 표현식은

$$r = r_1^*r_2(r_4+r_3r_1^*r_2)^*$$

**정리**: $L$이 regular language이면 $L=L(r)$인 정규 표현식 $r$이 존재한다.

**증명 스케치**. $L$을 인식하는 NFA $M$이 있다고 하자. 일반성을 잃지 않고 $M$의 종료 state는 하나뿐이고 $q_0 \notin F$라 가정할 수 있다. $M$을 GTG로 간주하고 state 제거법을 반복 적용해 canonical form까지 줄이면, 그 결과가 바로 $L$을 나타내는 정규 표현식이다. $\blacksquare$

#### 예시
$\Sigma = \{a,b\}$에서 $L = \{w \in \{a,b\}^* \mid n_a(w)$는 짝수, $n_b(w)$는 홀수$\}$

$a$의 개수의 짝/홀, $b$의 개수의 짝/홀 4가지 조합을 state (EE, EO, OE, OO)로 표현한 DFA를 만들고, state 제거법을 EO, OO(시작 EE, 종료 OE라 하면 중간 state)에 적용하면

$$r = a^*b(bb)^*a\,(a + b(bb)^*ba)^*\,a(bb)^*$$

와 같은 형태의 (교재별로 표현이 다를 수 있는) 정규 표현식을 얻는다. 핵심은 "제거 순서와 무관하게 최종적으로 남는 canonical form에서 정규 표현식을 읽어낼 수 있다"는 점이다.

### 3. 정규 표현식의 대수적 법칙

- **교환/결합 법칙**
    - $r_1 + r_2 = r_2 + r_1$ (합집합은 교환 가능)
    - $r_1 r_2 \neq r_2 r_1$ (연쇄는 교환 불가능 — 순서가 있는 연산이므로)
    - $(r_1+r_2)+r_3 = r_1+(r_2+r_3)$
    - $(r_1 r_2) r_3 = r_1 (r_2 r_3)$
- **항등원/영원**
    - $\emptyset + r = r + \emptyset = r$ ($\emptyset$은 union의 항등원)
    - $\epsilon r = r\epsilon = r$ ($\epsilon$은 concatenation의 항등원)
    - $\emptyset r = r \emptyset = \emptyset$ ($\emptyset$은 concatenation의 영원 — 아무 문자열도 만들 수 없으므로)
- **분배 법칙**
    - $r_1(r_2+r_3) = r_1r_2 + r_1r_3$ (좌측 분배)
    - $(r_2+r_3)r_1 = r_2r_1 + r_3r_1$ (우측 분배)
- **멱등 법칙(idempotent law)**: 일반 산술연산은 $x+x\neq x$, $x\times x\neq x$이지만, 정규 표현식의 union은 $r+r=r$ (집합의 합집합이므로 중복이 그대로 흡수됨)
- **closure에 관한 법칙**
    - $r^{**}=r^*$ (스타를 두 번 씌워도 한 번과 동일)
    - $\emptyset^* = \epsilon$, $\epsilon^*=\epsilon$
    - $r^+ = rr^* = r^*r$ (positive closure는 star-closure에서 $\epsilon$만 뺀 것과 동치)
    - $r^* = r^+ + \epsilon$

## 비정규 언어의 증명

### 비둘기집 원리(Pigeonhole Principle)를 이용한 증명

**원리**: $n$개의 물건을 $m$개의 상자에 넣을 때 $n>m$이면 적어도 한 상자에는 2개 이상의 물건이 들어간다.

**예제**: $L=\{a^nb^n \mid n\ge 0\}$이 정규 언어가 아님을 보여라.

**증명**. $L$이 regular라고 가정하면 DFA $M=(Q,\{a,b\},\delta,q_0,F)$가 존재한다. $\delta^*(q_0,a^i)$, $i=1,2,3,\dots$를 생각하면 $i$는 무한히 많지만 state는 유한하므로, 비둘기집 원리에 의해

$$\delta^*(q_0,a^n)=q=\delta^*(q_0,a^m),\quad m\neq n$$

인 $m,n$이 존재한다. $M$이 $a^nb^n$을 accept하므로 $\delta^*(q,b^n)=q_f\in F$. 그런데 그러면

$$\delta^*(q_0,a^mb^n)=\delta^*(\delta^*(q_0,a^m),b^n)=\delta^*(q,b^n)=q_f$$

즉 $a^mb^n$($m\neq n$)도 accept되어 모순. 따라서 $L$은 regular가 아니다. $\blacksquare$

### 펌핑 렘마(Pumping Lemma)

**정리**. $L$이 무한한 regular language이면, 어떤 양의 정수 $m$이 존재하여 $L$의 임의의 문자열 $w$($|w|\ge m$)는

$$w = xyz,\qquad |xy|\le m,\ |y|\ge 1$$

로 분해될 수 있고, 모든 $i=0,1,2,\dots$에 대해 $w_i = xy^iz \in L$이다.

즉, 충분히 긴 문자열은 3부분으로 나뉘어 가운데 부분($y$)을 몇 번이든 반복(pumping)해도 여전히 $L$에 속한다.

**증명**. $L$을 인식하는 DFA의 state가 $q_0,q_1,\dots,q_n$이라 하자. $|w|\ge m=n+1$인 $w \in L$을 잡으면, $w$를 처리하며 지나가는 state 수열은 길이 $|w|+1$이므로 비둘기집 원리에 의해 $n+1$번째 이동 이내에 반드시 어떤 state가 반복된다. 즉 수열은

$$q_0\ q_i\ q_j\ \cdots\ q_r\ \cdots\ q_r\ \cdots\ q_f$$

와 같은 형태이고, 이에 대응하는 문자열 $x,y,z$가

$$\delta^*(q_0,x)=q_r,\quad \delta^*(q_r,y)=q_r,\quad \delta^*(q_r,z)=q_f$$

를 만족하며 $|xy|\le n+1=m$, $|y|\ge 1$이다. 여기서 $y$는 state $q_r$에서 시작해 다시 $q_r$로 돌아오는 loop이므로, 몇 번을 반복하거나(pumping) 아예 건너뛰어도($y^0$) 여전히 $q_0$에서 $q_f$로 도달한다:

$$\delta^*(q_0,xz)=\delta^*(q_0,xyz)=\delta^*(q_0,xy^2z)=\cdots=q_f \qquad \blacksquare$$

#### 적용 시 주의사항
- 펌핑 렘마는 $m$과 분해 $xyz$의 **존재**만을 보장하며, 그 값이 무엇인지는 알려주지 않는다.
- 특정 $m$이나 특정 분해에 대해서만 펌핑 렘마가 성립하지 않는다고 해서 곧바로 모순이라 할 수 없다 (다른 분해에서는 성립할 수 있으므로).
- 반대로, 펌핑 렘마는 **모든** $w\in L$과 **모든** $i$에 대해 성립해야 하므로, 단 하나의 $w$나 $i$에 대해서라도 위배되면 그 언어는 regular가 아니다.

#### 적대적 게임(adversarial game)으로 이해하기
1. 상대방이 $m$을 고른다.
2. 우리는 $m$이 주어졌을 때, $|w|\ge m$인 $w\in L$을 자유롭게 고른다.
3. 상대방이 $|xy|\le m,\ |y|\ge1$을 만족하는 분해 $xyz$를 고른다 (우리에게 가장 불리하게).
4. 우리는 $xy^iz \notin L$이 되는 $i$를 찾아내면 승리 — 이것이 가능하면 $L$은 regular가 아님을 증명한 것이다.

#### 예제
- $L=\{a^nb^n\mid n\ge0\}$: $w=a^mb^m$을 고르면, $|xy|\le m$이므로 $xy$는 전부 $a$로만 이루어짐 ($y=a^k, k\ge1$). $xy^2z = a^{m+k}b^m \notin L$. 따라서 $L$은 regular가 아니다.
- $L=\{ww^R \mid w\in\Sigma^*\}$: $w=a^mb\,ba^m$ 형태를 고르면 마찬가지로 $y$는 앞쪽 $a$들 중 일부이고, 펌핑하면 팰린드롬이 깨진다.
- $L=\{0^i1^j \mid i>j\}$: $w=0^{m+1}1^m$을 고르면 $xy$는 $0$들만으로 이루어지므로 $y=0^k$, $xy^0z=0^{m+1-k}1^m$이 되어 $i>j$ 조건이 깨질 수 있다(펌핑 다운, $i=0$).

## 정규 언어의 폐포 성질(Closure Properties)

정규 언어 family는 다음 연산에 대해 **닫혀 있다(closed)**:

1. 합집합 / 교집합
2. 여집합(complementation)
3. 차집합
4. 역순(reversal)
5. star-closure
6. concatenation
7. 준동형사상(homomorphism)
8. 역준동형사상(inverse homomorphism)

### Union, Concatenation, Star-closure
$L_1,L_2$가 regular이면 정규 표현식 $r_1,r_2$가 존재해 $L_1=L(r_1),L_2=L(r_2)$. 그러면 $r_1+r_2,\ r_1r_2,\ r_1^*$ 역시 정규 표현식이므로 $L_1\cup L_2,\ L_1L_2,\ L_1^*$도 regular이다. (자명)

### 여집합(Complementation)
$M=(Q,\Sigma,\delta,q_0,F)$가 $L_1$을 accept하는 DFA라면, $\overline M=(Q,\Sigma,\delta,q_0,Q-F)$는 $\overline{L_1}$을 accept한다 (종료 state와 비종료 state를 뒤바꾸기만 하면 됨). 따라서 $\overline{L_1}$도 regular.

> 주의: 이 논법은 **DFA**에서만 바로 성립한다. NFA는 종료 state를 뒤집는다고 여집합이 되지 않는다 (여러 경로 중 하나만 accept해도 되므로).

### 교집합(Intersection)
$L_1=L(M_1),\ L_2=L(M_2)$, $M_1=(Q,\Sigma,\delta_1,q_0,F_1)$, $M_2=(P,\Sigma,\delta_2,p_0,F_2)$라 하자. 두 DFA를 **곱 오토마타(product automaton)**로 결합한다:

$$\hat M = (Q\times P,\ \Sigma,\ \hat\delta,\ (q_0,p_0),\ F_1\times F_2)$$

$$\hat\delta((q_i,p_j),a) = (q_k,p_l) \iff \delta_1(q_i,a)=q_k,\ \delta_2(p_j,a)=p_l$$

즉 두 DFA를 동시에 시뮬레이션하는 하나의 state로 표현하고, 둘 다 종료 state일 때만 종료 상태로 인정한다. $w\in L_1\cap L_2 \iff \hat M$이 $w$를 accept. 따라서 $L_1\cap L_2$도 regular이다.

대안적으로 De Morgan의 법칙 $L_1\cap L_2=\overline{\overline{L_1}\cup\overline{L_2}}$을 이용해, 여집합과 합집합의 폐포성으로부터 교집합의 폐포성을 유도할 수도 있다.

### 차집합(Difference)
$L_1-L_2 = L_1 \cap \overline{L_2}$이므로, 교집합과 여집합의 폐포성으로부터 바로 따라온다.

### 역순(Reversal)
$L$이 regular이면 종료 state가 하나뿐인 NFA를 만들고, 시작 state와 종료 state를 서로 바꾸고 모든 edge의 방향을 뒤집으면 $L^R$(각 문자열을 거꾸로 읽은 언어)을 인식하는 NFA가 된다.

### 준동형사상(Homomorphism)
**정의**: 두 알파벳 $\Sigma,\Gamma$에 대해 함수 $h:\Sigma\to\Gamma^*$를 준동형사상이라 한다. 즉, 하나의 문자를 하나의 문자열로 치환하는 대응이다.

$w=a_1a_2\cdots a_n$이면 $h(w)=h(a_1)h(a_2)\cdots h(a_n)$, 그리고 $L$에 대해 $h(L)=\{h(w)\mid w\in L\}$.

**예시**: $\Sigma=\{a,b\}$, $\Gamma=\{a,b,c\}$, $h(a)=ab$, $h(b)=bbc$라 하면 $h(aba)=h(a)h(b)h(a)=ab\,bbc\,ab$. $L=\{aa,aba\}$의 준동형 이미지는 $h(L)=\{abab,\,abbbcab\}$.

정규 표현식 $r$이 $L$을 나타낼 때, $r$의 각 $\Sigma$-심볼에 $h$를 그대로 적용하면 $h(L)$을 나타내는 정규 표현식 $h(r)$을 얻는다. 따라서 **임의의 준동형사상에 대해 정규 언어의 family는 닫혀 있다**.

## DFA의 최소화(Minimization)

하나의 언어를 인식하는 DFA는 유일하지 않다 — 여러 개의 (동치인) DFA가 존재할 수 있다. 그중 state 수가 최소인 DFA를 찾는 것이 최소화의 목표다.

### 구분 불가능한 상태(Indistinguishable States)

**정의**. DFA의 두 state $p,q$가 **구분 불가능(indistinguishable)**하다는 것은, 모든 $w\in\Sigma^*$에 대해

$$\delta^*(p,w)\in F \iff \delta^*(q,w)\in F$$

**정의**. 어떤 문자열 $w$가 존재해 $\delta^*(p,w)\in F$이면서 $\delta^*(q,w)\notin F$ (혹은 반대)이면, $p,q$는 그 $w$에 의해 **구분 가능(distinguishable)**하다고 한다.

### 구분 가능한 상태 쌍 찾기 (marking 알고리즘)

1. 도달 불가능한 state를 모두 제거한다.
2. 모든 state 쌍 $(p,q)$에 대해, $p\in F, q\notin F$(또는 그 반대)이면 $(p,q)$를 구분 가능으로 표시한다.
3. 더 이상 새로 표시되는 쌍이 없을 때까지 반복: 모든 쌍 $(p,q)$와 모든 $a\in\Sigma$에 대해 $p_a=\delta(p,a),\ q_a=\delta(q,a)$를 계산하고, $(p_a,q_a)$가 구분 가능으로 표시되어 있으면 $(p,q)$도 구분 가능으로 표시한다.

이 과정이 끝나면 표시되지 않은 쌍들이 바로 구분 불가능한 상태들이고, 이들을 하나로 묶어 새로운 state로 만드는 것이 **reduced DFA**이다.

### Reduced DFA 구성법

$M=(Q,\Sigma,\delta,q_0,F)$가 주어졌을 때, $\hat M=(\hat Q,\Sigma,\hat\delta,\hat q_0,\hat F)$를 다음과 같이 구성한다.

1. 위 알고리즘으로 구분 불가능한 state들의 그룹 $\{q_i,\dots,q_k\},\{q_l,\dots,q_n\},\dots$을 찾는다.
2. 각 그룹마다 새로운 state(레이블은 그룹에 속한 state 번호들을 이어붙임)를 만든다.
3. 원래 전이 $\delta(q_r,a)=q_p$에 대해, $q_r$이 속한 그룹과 $q_p$가 속한 그룹을 찾아 그 사이의 전이로 정의한다.
4. $q_0$가 속한 그룹이 새로운 시작 state이다.
5. $F$에 속한 state를 포함하는 그룹들이 새로운 종료 state 집합이다.

이렇게 구성된 $\hat M$은 $M$과 동치이면서 state 수가 최소인 DFA가 된다. (직관적으로: 서로 다른 그룹에 속한 state들은 언젠가 accept 여부가 갈리므로 합칠 수 없고, 같은 그룹 안의 state들은 항상 같이 움직이므로 합쳐도 안전하다.)

## 정규 문법(Regular Grammar)

### 문법(Grammar)의 정의

**정의**. 문법 $G$는 4-tuple $G=(V,T,S,P)$로 정의된다.
- $V$: 변수(variable)들의 유한 집합
- $T$: 터미널(terminal) 기호들의 유한 집합 ($V\cap T=\emptyset$)
- $S\in V$: 시작 변수(start variable)
- $P$: 생성 규칙(production)들의 유한 집합

예: $G=(\{S\},\{a,b\},S,P)$, $P: S\to aSb \mid \epsilon$이면 $S\Rightarrow aSb \Rightarrow aaSbb \Rightarrow aabb$처럼 유도되며 $L(G)=\{a^nb^n\mid n\ge0\}$.

### 우선형(Right-linear) / 좌선형(Left-linear) 문법

**우선형 문법**: 모든 생성 규칙이 $A\to xB$ 또는 $A\to x$ 꼴 ($A,B\in V$, $x\in T^*$) — 변수가 있다면 항상 오른쪽 끝에만 위치.

**좌선형 문법**: 모든 생성 규칙이 $A\to Bx$ 또는 $A\to x$ 꼴 — 변수가 있다면 항상 왼쪽 끝에만 위치.

**선형 문법(linear grammar)**: 어떤 생성 규칙의 우변에도 변수가 최대 하나만 나타나는 문법 (위치 제한은 없음). 예: $S\to S_1ab,\ S_1\to S_1ab\mid S_2,\ S_2\to a$.

**정규 문법(regular grammar)**: 우선형이거나 좌선형인 문법. (선형 문법 중에서도 변수의 위치가 한쪽으로 고정된 특수한 경우)

#### 예시
$G=(\{S,S_1,S_2\},\{a,b\},S,P)$, $P:\ S\to S_1ab,\ S_1\to S_1ab\mid S_2,\ S_2\to a$ (좌선형)

$S\Rightarrow S_1ab \Rightarrow S_1abab \Rightarrow S_2abab \Rightarrow aabab$

이므로 $L(G) = \{aabw \mid w\in\{ab\}^*\}$, 대응하는 정규 표현식은 $r=aab(ab)^*$이다.

### 정규 문법과 정규 언어의 동치성

**정리**. $G$가 우선형 문법이면 $L(G)$는 regular language이다. (직관: $A\to xB$는 "$x$를 읽고 $B$ state로 전이"에, $A\to x$는 "$x$를 읽고 종료 state로 전이"에 그대로 대응되므로 NFA로 직접 변환 가능)

**정리**. $L$이 regular language이면, $L=L(G)$인 우선형 문법 $G$가 존재한다. (직관: DFA/NFA의 각 전이 $\delta(q,a)=p$를 생성 규칙 $q\to ap$로 바꾸면 됨)

**정리**. $L$이 regular $\iff$ $L=L(G)$인 좌선형 문법 $G$가 존재.

**정리**. $L$이 regular $\iff$ $L=L(G)$인 정규 문법(우선형 또는 좌선형) $G$가 존재.

즉, **정규 문법 $\iff$ 정규 언어 $\iff$ 정규 표현식 $\iff$ DFA $\iff$ NFA** 는 모두 동치인 개념이다.
