## Levelorder
``` c
void level_order(NODE* h){
	NODE* queue[100] = { 0 } ;
	int front = 0, rear = 0;
	NODE* p = NULL;
	
	if(h == NULL){
		return;
	}
	
	queue[rear++] = h;
	while(front < rear){
		p = queue[front++];
		printf("%d ", p->data);
		
		if(p->left){ queue[rear++] = p-> left; }
		if(p->right){ queue[rear++] = p-> right; }
	}
	
	return;
}
```

## Heap
**Insertion**
배열로 구현
배열의 끝자리 + 1에 일단 넣음
parent와 비교해서 자신이 더 크면
parent를 child 자리에 복사
parent자리에 넣으려던 값을 넣음

**Deletion**
일단 root 출력하고 끝자리를 temp (arr[0]번 자리) 에 넣음
parent는 root, child는 왼쪽 child지정

위치 찾기 반복문:
	오른쪽 child 가 더 크면 child ++
	(root의 child 비교해서 큰 값을 지정)
	temp가 child 보다 크면 break
	아니면 child를 parent로 옮기고 
	child, parent 재지정.

 parent자리에 temp 값 삽입

# 07 sort
## 1. Iterative sort
시간 복잡도: O(n)
평균적으로 (n+1) / 2
## 2. Binary sort
시간 복잡도: O(log n)
## 3. Insertion sort
앞에서부터 정렬

시간 복잡도
worst case: O(n^2) (내림차순)
best case: O(n) (오름차순)
작은 사이즈에 유리

## 4. Quick sort
pivot써서 재귀치는거

시간 복잡도
worst case: sublist두개의 길이가 많이 차이나는 경우 (오름차순, 내림차순)
optimal case: O(n log n)

## 5. Merge sort
정렬된 배열 두개를 새 배열에 넣는거 (재귀, 스택)

시간 복잡도
O(n log n)
n <= 15 면 그냥 insertion이 더 빠름
공간 복잡도
O(n)

## 6. Heap sort

시간 복잡도
O(n log n)
