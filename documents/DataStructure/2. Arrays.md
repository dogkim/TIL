**Fast Transpose**
원본 matrix
데이터 개수 count

전치후 메트릭스 tuple res[]
열 개수 colcount = matrix[0].col

열의 데이터마다 개수 몇개인지 col_count
이후 데이터 들어가는 위치 startpos

```C
for (int i = 1; i< count; i++){
col_count[matrix[i]]++;
}
```

startpos[0] = 1
```C
for(int i =1; i<colcount ; i++){
startpos[i] = startpos[i-1] + colcount[i-1];
}
```

res[0].row = matrix[0].col
res[0].col = matrix[0].row
res[0].data = matrix[0].data
```C
int j = startpos[matrix[i].col]++;
res[j].col = matrix[j].row;
res[j].row = matrix[j].col;
res[j].data = matrix[j].data;
```
